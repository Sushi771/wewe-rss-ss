# Redbook 本地交付边界

原小红书页的“打开首次小检查”入口提供待核对笔记的标题、正文、发布时间、完整图片数量，以及最多两张诊断预览。诊断预览不能替代全图核对。页面按服务端返回值展示会话失效时间：诊断会话最多 24 小时，人工核对后启用的正式归档会话最多两小时，且不超过原诊断会话剩余期限。

人工核对成功只启用来源。继续点击原页面“刷新此博主”，才会归档图文；通过原有本地导出入口保存正文和图片。重复扫描跳过完整详情和媒体；同目录、跨日期导出依靠稳定身份跳过完整文件，只补缺图并保留手写正文。

关闭弹窗或卸载页面会中止前端请求并阻止迟到结果更新界面，不会撤销已在后端创建的会话。需要撤销时使用明确的撤销操作。人工核对成功后若页面状态同步失败，界面区分归档来源已启用和页面状态未同步，避免误报核对失败。

本地兼容候选包含生产基线 d8c35aa9ca2e1d74bedd1ab30cbd0acea4ec5434 的开发分支合并。合成测试覆盖实际 Nest 管理入口、诊断、人工核对、原刷新、SQLite 和原 HTTP 本地导出链路，包含两张独立有效 PNG、跨日期跳过、补缺图与手写正文保留。启动器测试覆盖就绪预算、失败阶段与安全输出。实际系统目录选择器仅使用合成替身。

这些结果证明本地接线与合成数据行为，不证明真实平台签名、账号权限、真实全文或原图可用。默认无会话关闭；安装会话不自动刷新；受限响应后不自动换签、HTML 回退或换端点。本轮不进行真实平台请求、登录或凭据获取。

真实平台验收仍须另行明确授权。届时人工一次完成作者身份、全文、全部图片顺序及发布时间核对，再手动刷新并检查导出文件。没有这一步，不将 liveValidation:pending 改称真实接口已验收。开发交付与远端检查见 [PR26](https://github.com/Sushi771/wewe-rss-ss/pull/26)，以该 PR 当前精确 SHA 的结果为准；保持 draft，未部署生产。
