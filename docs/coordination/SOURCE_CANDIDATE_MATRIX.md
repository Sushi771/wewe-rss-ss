## 下一轮可执行问题

1. 与 A 线合并证据：`/book/articles` 的 `skey/vid` 若能从本人正常登录和可续期生命周期明确取得，交 Probe 做**一次**只读首屏。先记录 HTTP/业务状态、`reviews` 数量和字段存在性；取到条目后再验五篇、身份、发布时间、分页、正文、图。
2. 与 C 线合并证据：已找到可审查的公开文章→所属合集代码，先用目标已确认原文离线核 `tags/appmsgalbuminfo`，由 C 线确认确切 `album_id`、`hid` 或作者放置的主页栏目链接，再交 Probe。旧文章只作身份种子，不冒充新增文章；一个合集也不冒充全号。
3. 对后台 `free_publish`/`publish` 只追近期真实跨号响应和腾讯前端调用；若无新增证据，现有源码只是候选，不因为 PR 活跃就重试受限后台。

这些是已定位的可执行研究条件；矩阵没有给出“仅剩外部条件”或“自建不可能”的结论。
