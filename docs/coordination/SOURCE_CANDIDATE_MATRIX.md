## 下一轮可执行问题

1. `/book/articles` 认证映射仍缺**正常签发或续期的旧 `skey` 自定义头与现有合法会话之间的明确代码证据**，近期 `accessToken/vid` 客户端并未证明两者等价；保留不同于 `/mp/chapters` 的独立候选。找到该映射和当前列表真实回包或同源调用依据后，交独立 Probe 做**一次**低频只读首屏，先记录 HTTP/业务状态、`reviews` 数量和字段存在性；取到条目后再验五篇、身份、发布时间、分页、正文、图。
2. C 线已从已核验旧文章发现两个目标官方合集，并对另一篇旧长链只请求一次得到 302；八份保存原文的正文链接又离线发现 60 个两合集外的同号完整文章键。先核未请求种子及公开页身份/原文时间，旧文章与旧链接只作发现种子，不冒充新增文章，也不把互链当全号目录。

4. 5. 独立 Probe 可用**本人正常登录的官方搜索页面**对目标准确号名作首屏；只有首屏返回有效目标卡片且官方页面显示可继续时，才考虑一次自然滚动对照，记录卡片新增数和身份。遇验证码或登录失效即停。公开证据只证明页面在其他号/关键词、较早日期曾加载更多，不证明 2026-09 目标可分页；过期扫码需本人完成。
6. 移动公开索引待找到 `type=2` 文章卡片的真实请求、解析与近期成功证据；原生 `/wxsearch/broker` 待找到公开宿主把相对 path 转成腾讯 HTTP 的代码、正常认证和续期链。导航 URL 与 JS 桥适配层本身均不能作为可部署 Provider 或无依据探针。

这些是已定位的可执行研究条件；矩阵没有给出“仅剩外部条件”或“自建不可能”的结论。
