# 搜狗移动单篇跳转校准（2026-09-30）

## 已审前提

此前[源码审计](SOGOU_MOBILE_LINK_SOURCE.md)确认移动文章标题为普通 `h4 a[href]`，但其搜狗 `/link` 目标是不可离线解释的不透明值。为了测试**同会话移动搜索能否定位一篇已知文章**，本轮从生产 SQLite 中只读选择一篇原已验证的目标旧文。读取使用 `DatabaseSync(..., { readOnly: true })`、`PRAGMA query_only=ON` 和 `quick_check=ok`；校准种子有 `verified_source_url` 的 `__biz/mid/idx/sn` 四字段、既有正文缓存和可信发表时间。其标题作为新搜索词，**与此前目标号名首屏查询不同**；旧文只作校准，绝不计作新订阅文章。本文不公开标题、四字段值、原文 URL 或搜狗结果 URL。

[`probe-sogou-mobile-link-calibration.cjs`](../../scripts/research/probe-sogou-mobile-link-calibration.cjs) 在联网前独占建立用户主目录私有哨兵并同步落盘；本次目标词对应哨兵已存在，重复运行会在发送前停。代码对搜狗只允许 `https://weixin.sogou.com/weixinwap` 和页面给出的 `/link`，一次 GET、无代理、无自动跳转、无重试，8 秒超时，搜索体最多 128 KiB、跳转体最多 64 KiB。它只从**本次**搜索响应 Set-Cookie 按 Domain/Path 规则构成进程内 Cookie，且仅在卡片标题、来源精确匹配后才可请求一个 `/link`。它不请求微信原文、不执行搜狗 JS，也不写生产库。私有证据只含状态、请求数、状态码、字节数、内容摘要、结构计数及脱敏跳转主机/路径；原始响应、Cookie、标题和完整 URL 均不落盘。代码用合成响应做五组离线自测：成功的 HTML 分段 URL、缺 Cookie、验证码、卡片不匹配、验证码跳转；加上 Cookie Domain/Path 与重复哨兵断言，真实网络调用为零。

## 一次真实搜索的结果

执行前预检：旧文身份四字段有效，标题长度 17，生产库可读，目标哨兵不存在；离线自测五组通过。随后只执行一次**标题查询**：

| 搜狗移动搜索 | 值 |
| --- | --- |
| 实际网络请求 | `GET /weixinwap?type=2&query=<旧文标题>` 一次 |
| HTTP / 内容 | 200 / 完整 HTML，49,353 字节，未触及大小上限 |
| 文章卡 | 10 张 `li[id^=sogou_vr_]` |
| 标题和目标号名同时精确匹配 | **0 张** |
| Set-Cookie 头 | 4 条；因卡片门禁失败，未用于下一请求 |
| `/link` 与微信原文请求 | **均为 0** |
| 私有最终状态 | `card-mismatch-stop`；持久哨兵与脱敏摘要位于用户主目录 `.wewe-rss-private/sogou-mobile-link-calibration/`，不入 Git |

这只排除“**本次旧文标题查询能够拿到该旧文的同号精确卡片**”这一前提。由于原始搜索 HTML 按设计没有保存，现有摘要无法区分卡片是标题未匹配、来源未匹配，还是两者均不匹配；不得从十张卡推成十篇目标文章，也不能认定该旧文不存在于搜狗其他查询结果。**本轮没有测试移动 `/link` 的 HTTP 行为**，也没有复验先前号名首屏、匿名页 2 或桌面 `/link`。搜索页上的四个 Set-Cookie 仅证明服务器返回了头，不证明它们符合 `/link` 的 Domain/Path 门禁或后续跳转可用。

另以**纯离线**方式，把此前私有保存的目标号名移动首屏中 8 张同名卡的标题，与生产 SQLite 只读取得的 20 篇已核目标旧文标题按 Unicode NFC、连续空白归一后比较，**精确匹配为 0**。这 20 篇旧文均发表于 2026 年 9 月；已保存的首屏卡对应更早的页面快照。没有输出标题、文章身份或 URL，也没有重发该首屏或访问其 `/link`。此结果只说明已保存的八张卡不能用这批旧文校准身份，不能说明移动搜索没有近期文章。

此校准尚未得到腾讯官方文章 URL，因而目标身份、原文 `ct`、正文、图片、分页和自然更新均没有新增验收证据。下一轮若找到有一手支持的不同发现词或官方原文线索，可以另设独立假设与哨兵；不能重发本次标题查询来试运气，更不能因这次无精确卡片宣布移动索引或自建订阅整体失效。
