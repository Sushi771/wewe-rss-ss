## 对本项目的判定

目前可确认的无中转来源是**腾讯官方浏览器自然发出的请求**：正常登录使浏览器具备 Web Cookie，第一方 JS 为每次请求提供 `x-wrpa-0`，若腾讯要求人机验证，由本人完成验证码后网页才临时携带 `x-wr-ticket`。但已审实现取得这些值均靠监听或手工复制请求；`wpa-1.0.5.js` 内部不可独立审查，未见官方可调用的票据签发/续期接口，也未见不用监听网络响应、仅从可见页面 DOM 稳定取得身份、发布时间和分页数据的公开实现。因此，**尚未建立符合本项目无人值守订阅边界的长期调用链**。这仅排除“保存并重放一次票据”以及“Cookie 续期等于票据续期”的推断；不排除官方页面在本人合法登录下展示文章、其他公开来源，或将来发现新的可审查方式。

可继续的独立核查是：固定当前 MP 阅读器其他加载块，静态确认其正常页面是否把完整 `reviews` 列表、发布时间和下一页控制映射成可读 DOM；另找腾讯维护说明或带原始脱敏成功响应的一手证据，确认 `/web/login/renewal` 是否实际返回票据头。两项都不要求重复发目标列表请求。任何未来浏览器合法验证都应由本人处理登录/验证码，且只对**新认证上下文**设计一次隔离只读测试；不能重发旧 `-2041` 形状或把 GZHReader 的监听模式直接移植为产品。
