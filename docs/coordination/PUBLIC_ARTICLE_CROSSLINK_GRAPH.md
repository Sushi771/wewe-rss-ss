# 目标号正文互链：缓存正文的离线结构审计（2026-09-30）

## 输入与边界

2026-09-27 的八份目标官方原文 HTML 和四页合集 JSON 已从原临时目录消失，本轮不能重算它们的 DOM、`172` 次引用或 `63` 个目标键。已提交的 [原始审计记录](PUBLIC_PAGE_DISCOVERY.md#正文同号互链旧目标原文中发现两合集之外的身份种子仅离线) 仍说明那 `172` 条出自八份页面的 `#js_content a[href]`，不能再细分当时的父节点、顺序、锚文本或所属段落。本轮没有以哨兵缺失推断任何 URL 未请求，也没有网络请求。

另有一份**不同的持久输入**：生产 SQLite 中目标号的旧 `content_html` 缓存。用 [`crosslink-graph-offline.cjs`](../../scripts/collection-source-probe/crosslink-graph-offline.cjs) 对它执行 `DatabaseSync(..., { readOnly: true })` 与 `PRAGMA query_only=ON`，先得 `quick_check=ok`，只查询目标号 `articles` 的旧正文、已核长链及行 ID。脚本仅输出聚合数，不输出数据库行 ID、文章标题、URL、`biz/mid/idx/sn`、正文或凭据。`content_html` 是导出用的清洗后正文，**不是丢失八页的原始 HTML**；本节统计不可与 `172/63` 合并，也不能推断同一键集。

187 个同号链接均是**带文字的正文锚点**：其直接父节点都是 `span`，最近的块元素为 `p`（179）或 `section`（8）；无一个位于 `li` 或标题元素内，也无图片型锚点。187/187 URL 都带 `scene` 和 `#wechat_redirect`；0/187 带 `ct` 或 `album_id`。这批缓存正文均未含 `album_info_list/appmsgalbuminfo/album_id` 或 `related_article` 字面字段。它们给出编辑正文中的跨文入口，而不是页面脚本里的官方合集卡片、`album_keep_read_info` 前后篇、推荐接口响应或账号目录。仅凭 `span/p/section` 结构不能推断编辑者怎样命名这段内容；清洗过程可能已删除原网页的布局和数据属性。

13 篇带同号链接的缓存正文中，只有 7 篇的库行还保存了可独立解析的已核四字段长链；其余 6 篇仅能依赖目标号库行的归属，不能由当前缓存重新核源篇的官方原文身份。上述图统计的源节点是库行，而不是逐篇重新取得并验过 `ct` 的当前原文。

源篇的旧 `publish_time` 只描述该源篇，目标链接不携带可核的目标原文 `ct`。链接顺序、出现次数和正文中的日期文字都不能替代目标原文发布时间。即使 75 个身份都对应真实同号文章，仍须逐篇从腾讯原文核 `biz/mid/idx/sn/ct`、正文和图片；这些旧正文引用本身不满足新增文章、分页或持续更新验收。

另已保存的 2026-09-28 目标旧文章当前官方短路径 HTML，先前独立只读审计确认 `#js_content` 中没有可点击链接、`album_info_list=[]`，也无目标合集声明。这是一篇不同的已核旧文章，说明“每篇目标文章都有互链或合集标签”不成立；本轮未重新请求它。

## 对下一步的约束

缓存正文只扩展了**候选身份池**，没有呈现由腾讯端点返回的同号列表、页游标、稳定前后篇规则、目标发布时间或自动发现合集的参数。已试正文长链摘要 `1c9ac9e993100643` 返回过一次 302，且旧临时哨兵已丢；不能从剩余 74 个缓存身份中仅按“目前没看到哨兵”选 URL 重发同形匿名长链。本专项没有提出新的在线请求。若将来有独立一手源码或当前官方页面证明另一种请求形状及身份来源，应先与已试 URL/请求账本交叉核对，再设计一次隔离只读验证；这份正文图不能充当该依据。

```powershell
node scripts/collection-source-probe/crosslink-graph-offline.cjs 'C:\absolute\path\to\wewe-rss.db'
```
