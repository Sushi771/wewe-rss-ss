## 已准备的一次性门禁

新增 [`public-old-shortpath-album-discovery.cjs`](../../scripts/collection-source-probe/public-old-shortpath-album-discovery.cjs)，沿用已经假网络验证的旧短路径探针的严格原文解析和私有原子保存逻辑，固定唯一摘要、UTC 日期与明示的 `--execute-reviewed-175e8ba5d396fb00-historical-unknown` 审查标志。`preflight` 只读重核生产库/备份、搜索 index 0 四字段交叉证据、已提交已试身份、现存私有及临时尝试标记；即使均未发现冲突，也输出 **`historicalShortVisit=historical_attempt_unknown`**。已知同篇任何 302、验证码或解析失败请求身份会在固定已试集合或现存 marker 门禁被排除；账本丢失风险继续由总控在执行前复审。

脚本只有携带上述精确标志且预检通过才可能发请求。它先在 Git 忽略持久目录排他并同步保存不含 URL 的尝试记录，再仅对**旧库存原样短路径**发一次匿名、无代理/Cookie/自动跳转/重试的 HTTPS GET，12 秒、6 MiB 上限；3xx、验证、403/429、非 HTML 或限额即停，不读取跳转目的。HTTP 200 的有界且非验证 HTML 先不可覆盖地私存，再核当前 `biz/mid/idx/sn`、短 canonical、字面 `ct`、严格正文和图片；身份/时间/正文通过才静态解析页面自身明确声明、与目标号相同的官方合集标签，原始 HTML 和精确标签仅保存在私有持久目录。公开结果只有布尔、计数与摘要。即使成功，也只验证一篇**旧文**是否可作为发现来源；合集列表、五篇新样本与持续更新须另验。带签名合集原文入口另见 [`THIRD_ALBUM_LONG_URL_COMPARISON.md`](THIRD_ALBUM_LONG_URL_COMPARISON.md)。
