14 行的旧时间是库内既存可信时间**对照值**，本轮没有重新取得当前页面字面 `ct`；不能拿它或已缓存正文证明今天可读。先前官方两合集旧 JSON 已丢，本轮也不能重新计算这些 14 行与任何合集的成员交集。生产库中其他旧行可能有短路径但缺严格长身份，均未纳入候选。

已提交 [`PUBLIC_PAGE_DISCOVERY.md`](PUBLIC_PAGE_DISCOVERY.md) 逐次记录此前三篇不同旧文的短路径 HTTP 200 与四字段、短 canonical、字面 `ct`、正文闭环；其中一篇后来由官方首屏证明属于第三合集。那时最近一次的私有持久哨兵仍在，另两次原来的 `%TEMP%` 尝试标记已丢。离线选种时系统 `%TEMP%` 顶层相关文章尝试标记为 **0**，私有持久短路径标记为 **1**；因此仅靠目录现状会把已知请求误判为“从未尝试”。此后新增的本篇持久哨兵使现存短路径标记变为 **2**；本篇不能再列为未请求候选。

选种时的报告能证明三条已经请求，不能为余下每条提供覆盖整个项目历史的未请求证明；本篇请求后已知短路径尝试数为 **4**，其余 **10** 行仍仅是“未见已提交短路径请求”。已保存目标旧原文曾有页面内官方合集标签，但不能据此推断其余任何一篇今天仍有标签，也不能把它们算新发表文章。

## 已准备的一次性门禁

新增 [`public-old-shortpath-album-discovery.cjs`](../../scripts/collection-source-probe/public-old-shortpath-album-discovery.cjs)，沿用已经假网络验证的旧短路径探针的严格原文解析和私有原子保存逻辑，固定唯一摘要、UTC 日期与明示的 `--execute-reviewed-175e8ba5d396fb00-historical-unknown` 审查标志。`preflight` 只读重核生产库/备份、搜索 index 0 四字段交叉证据、已提交已试身份、现存私有及临时尝试标记；即使均未发现冲突，也输出 **`historicalShortVisit=historical_attempt_unknown`**。已知同篇任何 302、验证码或解析失败请求身份会在固定已试集合或现存 marker 门禁被排除；账本丢失风险继续由总控在执行前复审。

脚本只有携带上述精确标志且预检通过才可能发请求。它先在 Git 忽略持久目录排他并同步保存不含 URL 的尝试记录，再仅对**旧库存原样短路径**发一次匿名、无代理/Cookie/自动跳转/重试的 HTTPS GET，12 秒、6 MiB 上限；3xx、验证、403/429、非 HTML 或限额即停，不读取跳转目的。HTTP 200 的有界且非验证 HTML 先不可覆盖地私存，再核当前 `biz/mid/idx/sn`、短 canonical、字面 `ct`、严格正文和图片；身份/时间/正文通过才静态解析页面自身明确声明、与目标号相同的官方合集标签，原始 HTML 和精确标签仅保存在私有持久目录。公开结果只有布尔、计数与摘要。即使成功，也只验证一篇**旧文**是否可作为发现来源；合集列表、五篇新样本与持续更新须另验。带签名合集原文入口另见 [`THIRD_ALBUM_LONG_URL_COMPARISON.md`](THIRD_ALBUM_LONG_URL_COMPARISON.md)。

离线验证：`node --check` 通过；在本机主仓真实生产库与私有搜索候选上运行 `preflight`，结果为 `preflight_pass`、`requests=0`、备份一致、私有候选身份匹配、该摘要**在选种时**无现存 marker 且历史状态为 `historical_attempt_unknown`。假网络 `selftest` 通过 302、非 HTML/限额、验证码、四字段冲突、解析停止、成功私存、网络失败和私有落盘失败八类；均没有真实网络请求。没有审查标志的 `probe` 在发请求前返回 `review_or_attempt_gate_stop`、`requests=0`。这些结果只说明脚本在**上线前**的门禁状态；总控随后的真实请求已建立持久哨兵。本轮不提交生产库、原文、完整 URL、标题、凭据或私有合集 ID。
