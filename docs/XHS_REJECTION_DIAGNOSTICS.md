# 小红书来源拒绝诊断

此变更纠正非标准 HTTP 拒绝状态被误判为验证码的行为。HTTP 461/471 本身不能证明当前网页有验证弹窗，也不能证明浏览器会话与采集会话一致。未知拒绝显示固定错误码 `XHS_SOURCE_UNKNOWN_REJECTION_BLOCKED` 并停止当前来源会话；明确重新连接前不得再次派发请求。

## 分类与隐私

- 认证、权限、签名、频控继续按既有 HTTP 状态及既有数字错误码识别。认证等既有明确分类优先于验证码提示。
- 只有 msg/message 完整匹配 `需要验证码`、`请完成验证码验证`、`captcha required` 才识别为来源明确提示验证。该白名单只是保守的诊断规则，不声称已确认真实平台字段契约。未知变体保持未知，不做关键词或子串猜测。
- 非 2xx 响应只在 JSON 且总量不超过 8192 字节（也不超过调用者限制）时解析。只有既有数字码 -100/-101/-104/300012/300015 和固定 `captcha required` 标记可离开传输层。其他字段、未知码、原始描述、Cookie、Token、URL、嵌套数据全部丢弃。
- 非 JSON、畸形 JSON、声明/实际过长、截断、超时或读取失败均退化为“仅状态”；不得将部分正文认定为诊断证据。重定向直接终止，不读取入口、不跟随 URL。
- 不返回任何验证链接，不自动打开来源响应 URL。来源提示验证不等于当前浏览器存在弹窗。
- 内存中有界接收与 JSON 解析不可避免地暂存响应字节；缓冲区清理时填零，不写日志或磁盘、不持久化原始响应。JS 字符串由垃圾回收管理，不能承诺密码学擦除。

## 停止与预算

未知拒绝与认证/验证等拒绝一样撤销 verified、禁用采集能力、取消在途会话信号并清除访问上下文。请求前预算扣额逻辑不变；拒绝不退款、不自动重试、不自动重新连接、不扩大限额或降低间隔。原任务检查点和已保存数据不因诊断变更而清除。

## 离线验证

合成测试覆盖 461/471 未知拒绝、明确验证码、认证优先级、恶意/带令牌 URL、未知错误码、超长文本和正文、非 JSON、畸形 JSON、超时、重定向、一次请求及会话硬停止。预算反例将合成账本设为仅剩一次配额，验证拒绝仍消耗该次预留，后续调用不进入预算或传输层；原始配额与停止状态均须保持。

本候选只完成代码与合成离线验证，未部署、未推送、未发送真实平台请求。真实 API 拒绝的原因和可用验证入口仍未确认。后续复验须在明确授权的环境中按原预算运行，记录接口类别、状态和固定安全分类；不得采集原始响应、私密参数或凭据作为诊断日志。
