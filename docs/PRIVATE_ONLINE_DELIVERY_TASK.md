## 用途与验收

应用供本人使用，配偶可偶尔使用；不开放公众注册、不收费、不作为公司多人系统。主线改为研究并实现**可自行维护的微信读书公众号订阅模块**：核心调用、身份核验和保存源码可审查、可自行构建部署，运行时不依赖第三方开发者的闭源中转或授权验证。可按许可证复用开源代码，不破解商业软件授权。暂停 Wechat2RSS 采购和部署，购买其授权不再是继续条件；现有 Wechat2RSS Provider 作为已完成工程成果保留，不作为当前真实订阅来源。

最终路径仍是：打开私人 HTTPS 地址登录 → 用公众号文章链接添加 → 手动或后台定时更新 → 浏览已保存文章 → 按公众号把 Markdown 与相对路径图片 ZIP 下载到浏览器所在电脑，解压后离线阅读。已有私人登录、数据库保护、正文图片与导出不得回退；不重写整个项目。

线上部署仍是最终目标，**取文能力先于部署采购验证**。已有 Windows 私有配置保留；本机 WSL、Docker 不是研究前置。先检查可复用资源；确认自建模块真实可用后再定部署容量、成本与方案。购买、账户授权、软件协议及本人扫码/官方验证由用户处理，未经确认不产生费用。

## 真实验收顺序

先按 [证据分析](WEREAD_SELF_HOSTED_RESEARCH.md)评估候选。本人已正常领取并私有保存腾讯官方 API Key；目标 `MP_WXS_3895431412` 的官方 `/book/chapterinfo` 单次只读实测返回空章节，`scope=4` 号名搜索单次收到 HTTP 499，均未达五篇门槛并已停止。继续只读核查有新依据、真正不同的取文实现；不能把相同请求换外壳重试。旧 `-2041` 和本次 HTTP 499 均不能解释为永久关闭、所有账号或全部自建路线不可用。

首轮门槛是“妈妈部落畅聊阁”至少 **5 篇真实不同文章**，逐篇核对公众号身份、稳定文章身份、原文链接与**发布时间**。`chapter.updateTime` 仅是章节更新时间，不能未经核对冒充发布时间。5 篇只作初轮样本，不是产品订阅上限。达标后再查分页、正文、图片和持续新增；近期订阅与订阅前全史分别验收。未达标不写生产库，不提前搭大块兼容接口或新管理界面。

首轮门槛及后续内容能力达标后，才接入现有 Provider 边界，于 SQLite 一致性副本验收导入、重复更新、旧字段保护、图片离线展示、按号 ZIP、迁移和重启。通过并重新核验备份后才受控写生产。生产再验证第二个号、全部原订阅、文章链接添加、单号更新、更新全部、定时触发、重启与浏览器下载。接手时重新核对订阅与文章数量，历史反馈的 12/1447 只作基线。

分别记录请求成功、读到已有缓存、真正取得新文章。登录、容器启动、Mock、CI 或一次脚本成功不是订阅恢复。订阅前全史、非群发内容及停机缺口单独记录，不阻断近期订阅；未出现自然新文时增量标待验。完成还须从干净环境按文档构建部署，凭据安全保存，依赖版本可追溯，故障诊断和回归测试可执行，旧文章与离线导出可用。
