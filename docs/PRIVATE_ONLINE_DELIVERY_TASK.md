# 私人线上部署、真实订阅、本地导出最终交付任务（2026-09-29）

## 用途与验收

应用供本人使用，配偶可偶尔使用；不开放公众注册、不收费、不作为公司多人系统。上游 Wechat2RSS 的个人合法授权由用户本人持有和管理，普通站点使用者不可接触激活码、Token 或上游管理权限。最终路径是：打开私人 HTTPS 地址登录 → 用公众号文章链接添加 → 手动或后台定时更新 → 浏览已保存文章 → 按公众号把 Markdown 与相对路径图片 ZIP 下载到浏览器所在电脑，解压后离线阅读。

线上部署是当前目标。已有 Windows 私有配置保留；本机 WSL、Docker 不是前置步骤。先检查现成云资源；没有时只选一个适合两个持久化服务的方案，核对官方价格，费用和最少的购买、账户授权、软件协议、扫码动作由用户处理。未经确认不产生新费用。

## 接手与保护

核对工作目录、分支、HEAD、未提交修改、远端和实际 SQLite 数量，以最新代码为准，不回退、不覆盖其他窗口修改。读本任务、`AGENTS.md`、`DEVELOPMENT_HANDOFF.md` 顶部、`SUBSCRIPTION_PROVIDER_DESIGN.md` 和相关代码；历史证据按需读取。保留现有 Provider、SQLite、文章身份映射、刷新冷却、正文处理和导出，修补实际缺陷。

禁止电脑微信窗口、滚动、剪贴板、抓包采集；不重试已等价失败的微信读书直连，不复刻旧中转。数据库、备份、环境文件、截图、原始证据不入 Git；凭据不输出到聊天或日志。生产写库前核验一致性备份，在副本完成迁移、真实导入与重复更新、旧字段保护、图片离线展示、按号导出及重启演练。

## 部署与访问

部署主应用与 Wechat2RSS 私有上游；SQLite、图片、上游数据持久化；HTTPS、私人访问控制、重启恢复和备份可验证。上游管理端和数据库不直接暴露公网。网页、RSS、正文、图片、下载接口都需要保护，默认不允许匿名内容访问或公开注册。用简单、可重复执行的方式部署，不引入 Kubernetes 或企业权限系统。浏览器导出必须返回 ZIP 文件，不能把服务器目录路径称为已下载。

## 真实验收顺序

尽早核对授权、实例和本人扫码条件。实例可用后，先在隔离环境验证“妈妈部落畅聊阁”至少 5 篇真实不同文章的公众号身份、稳定文章身份和原文链接、发布时间、正文，并选确有图片的文章验证附件下载。同实例比较 JSON Feed、RSS、`/api/query` 的真实字段后选择，不能凭猜测映射。

再于 SQLite 一致性副本验收导入、重复更新、旧字段保护、图片离线展示、按号 ZIP、迁移和重启。通过并重新核验备份后才受控写生产。生产再验证第二个号、全部原订阅、文章链接添加、单号更新、更新全部、定时触发、重启与浏览器下载。接手时重新核对订阅与文章数量，历史反馈的 12/1447 只作基线。

分别记录上游任务受理、读到已有缓存、真正取得新文章。登录、容器启动、Mock 或 CI 不是订阅恢复。订阅前全史、非群发内容及停机缺口单独记录，不阻断近期订阅；未出现自然新文时增量标待验。
