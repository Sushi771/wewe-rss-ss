## 打开本机工具

在运行软件的这台 Windows 电脑上，双击仓库根目录的`启动WeWe-RSS.bat`。它沿用已核受控启动器，读取活动包指针；已有同版本服务时复用，不再启动第二份，也不会停止外来进程。每次入口明确关闭定时刷新，成功后优先用本机Edge打开文章下载页；没有Edge则使用系统默认浏览器。启动失败时保留窗口里的错误，不打开页面。Git固定bat为Windows CRLF换行。

也可在这台电脑上打开 Edge 或 Chrome，把下面地址复制到浏览器地址栏并回车：

```text

```

`127.0.0.1` 指浏览器所在电脑。ChatGPT 内打开链接的页面不能作为这台电脑的本机浏览器验收；手机或其他电脑也无法通过该地址访问。2026-10-04 的空白反馈发生在 ChatGPT 内打开，服务仍为已核PID18288；独立本机Edge实际加载URL输入框和下载按钮，直接打开、刷新及尾斜杠路由均通过，JS/CSS返回200及正确类型。没有修改应用或部署包、开启公网、改变凭据或请求微信平台。当前工具的真实文章下载仍待另行验收。
