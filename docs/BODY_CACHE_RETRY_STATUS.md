# 正文缓存与错误反馈

文章列表只显示当前正文可用性：已缓存的正文可以阅读，缺少正文时显示未缓存并保留重试入口。历史重试失败和 HTTP 技术细节不常驻列表，也不放入该行的隐藏提示。

当前用户操作失败时给出简洁弹窗提示，并在后端保留失败结果和审计原因，便于后续诊断。移除界面展示不删除或改写历史记录，也不把过去的失败改成成功。

缓存下载继续核对实际正文和图片，历史失败不能取消已核验缓存的下载资格。已有正文、手写笔记、图片校验与重复导出保护保持原来的规则。缺正文时的重试仍为用户显式操作，不自动重试或跟随跳转。

页面渲染回归覆盖有缓存、缺缓存、旧失败后重新读取和当前操作失败提示；接口与下载规则沿用既有验证。代码和通用文档同步到对应 GitHub 草稿分支，运行审计保留本机。
