# 正文缓存与原文重试状态

当前正文缓存与上次原文重试分别显示。缓存存在时显示“正文已缓存，可阅读”；上次失败保留时间、脱敏原因，不代表当前缓存不可用。后续缓存同步成功也不清除真实失败历史。

缺少正文时才提供正文重试入口；单篇请求与现有订阅锁限制并发，不自动重试上游、不跟随 HTTP 302、不处理验证码或登录。网络故障可在恢复后由用户明确重试；已有正文优先使用本地阅读和下载入口。图片完整性仍由下载器实际校验，正文存在不等于导出完整。

下载时核对保存身份、实际正文和图片，不因历史 last_body_status=unavailable 拒绝已核验缓存；缺正文、坏图、身份冲突仍拒绝且不回退请求平台。所有诊断字段按白名单返回，不输出原始地址、Cookie 或服务器错误。

列表单篇“保存到 Obsidian”与批量离线 ZIP 共用的缓存出口也以实际正文为准，仍保留媒体不完整的失败标记与图片校验。列表和详情 API 不返回原始 lastBodyRetry JSON；数据库历史保持原样，只返回白名单字段。
