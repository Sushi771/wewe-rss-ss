- 单次请求只访问清理后的 `https://mp.weixin.qq.com/s` 完整链接，15 秒超时、10 MiB 上限，
  不跟随重定向、不自动重试，不读取微信会话或指标；沿用可选无凭据本机 HTTP 代理配置。
  其他查询参数不会随请求发送，已有来源字符串保留。
- 返回原文必须核对账号、biz/mid/idx、官方短链、标题与发布时间；验证/错误页、结构缺失、
  身份/标题/日期变化均失败。正文清洗后无文本或有效图片只记 unavailable，不推断删除或付费。
- 成功只补空正文、保存首次绑定及结果。已有非空正文、图片、封面、来源、标题、日期和有效/null 指标保留。
  请求期间重读文章；其他路径已补正文则保留，身份信息发生变化则拒绝保存。
  不创建新文章、不修改订阅通道、同步时间、定时开关或最近整号采集结果。

## API、备份与互斥

`article.retryBody(id)` 要求通过原有认证且为服务器本机请求。远程页面的入口不可操作，服务端也独立拒绝。
`article.list/byId` 返回 `bodyCached`、`bodyRetry.allowed/reason` 与解析后的 `bodyRetryResult`；
列表不返回正文内容。读取列表、RSS 或导出不会触发本入口。

通过预检后，在网络请求和任何结果写入之前执行并核验 SQLite 一致性备份；备份失败零请求、零写入。
复用服务内同号互斥，与手动/定时/公开合集/桌面采集互斥，同号不同篇也串行拒绝重入。
锁保持到结果事务结束。这是当前单服务进程内的互斥，不宣称提供多实例分布式作业锁。

`lastBodyRetry` 独立记录本次状态、固定错误码、时间、缓存是否可用及是否补入正文：

| 状态        | 含义                                                 |
| ----------- | ---------------------------------------------------- |
| available   | 本次取得有效正文，可能补空或沿用已有正文             |
| unavailable | 元数据已核验，本次没有取得正文，保留已有缓存         |
| failed      | 请求、页面、身份或保存失败，不覆盖之前正文与正文状态 |

失败返回明确 `status: failed`，页面使用错误提示，不伪装成功；HTTP/数据库原始错误不保存到结果中。
正文写入事务失败先回滚，再独立尝试记录失败；连失败状态都无法保存时返回错误，不报告已保存。
`lastBodyStatus` 仍只表示最近一次通过元数据核验的正文结果，与失败请求和缓存独立。

页面区分正文缓存、本次未取得正文及重试失败，请求期间禁用按钮，未知身份给出可见原因。
新结果会刷新列表与正文统计，最近一次结果有时间/说明提示。
实测修复了固定 44px 文章行导致重试按钮被表头遮挡的问题，现在文章行按内容增高。
