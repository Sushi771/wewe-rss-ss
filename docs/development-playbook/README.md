# 可靠本地应用开发手册

这里保存个人技能 `deliver-reliable-local-apps`（可靠本地应用交付）的非敏感项目副本，便于在项目开发和评审时复用。

## 使用方式

- 在支持个人技能的对话中调用 `$deliver-reliable-local-apps`，描述目标、环境、约束与验收条件。
- 在项目内从 [主流程](SKILL.md) 开始，按任务阅读 [数据与恢复](references/data-and-recovery.md) 或 [交互与交付](references/delivery-checklist.md)。
- 用 [案例与证据边界](references/cases.md) 理解方法，不把历史测试通过等同于当前生产解决。
