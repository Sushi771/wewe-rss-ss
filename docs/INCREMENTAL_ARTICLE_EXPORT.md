# 同目录增量保存与全周期导出

## 产品行为

订阅页的本机 Obsidian 保存以已确认目录、文章 ID、来源适配器和公众号 ID 为稳定身份。有效回执且正文与图片均存在、媒体完整时，先跳过，再决定是否创建临时目录或请求媒体。更换保存目录正常新增。改标题、发布时间、分组，不搬移原文章；手动编辑的正文与笔记保留。

界面分别统计新增、跳过、补齐、失败。媒体未完整（`mediaComplete=false`）计入失败，正文可能已经保存，不能解释为全部媒体归档。单篇失败继续处理其他篇；停止按钮、切换筛选或离开页面停止提交后续文章，当前已提交的单篇完成安全发布。重新点击可利用回执恢复，不用清除旧文件。

图片回执记录源图片临时名称到文章身份与字节哈希名称的映射。补齐仅请求映射中缺失的图片，已有有效图片复用，原图片引用恢复到相同文件名；下载字节改变则明确失败。原正文始终保留；库后来补入的新图片写入同目录 `.wewe-media-文章身份-补齐集合身份.md`，在 Obsidian 中通过该补齐说明查看，原正文不会自动插图。旧版共享目录回执没有映射时，内嵌归档图片可按实际哈希复用；仅含远程地址且无法安全建立映射的旧文件不能推断原图对应关系。旧单篇目录的不完整回执明确提示不能安全补齐，保留全部原文件。

损坏回执、正文缺失、图片字节被修改、链接文件、身份冲突和多个已有版本均明确失败，不静默覆盖或另存重复正文。来源回执不以标题判定身份。正常回执不校验用户正文哈希，因此允许用户编辑；新发布的中断日志另有正文哈希，只有完全写入的正文及图片才能恢复回执。中断产生的部分正文不会被当成成功，也不会覆盖。

“全选已加载”仍只选择当前已加载文章。“导出当前筛选全部到 Obsidian”先读取完整筛选的稳定 ID 快照，保留公众号、日期、分组和搜索语义，不受20篇页面限制；最多5000篇，超限明确要求缩小范围。上海日期开始含00:00，结束含当日最后一秒（下一日00:00不含），未知日期不纳入日期筛选。排序不改变范围成员。后续文章分次保存，范围冻结后新入库文章留给下一次导出。

ZIP 有独立入口：整号快照忽略日期、搜索和分组筛选；当前筛选 ZIP 保留这些条件。两个入口每次都在独立临时目录生成本次范围完整快照，不复用用户本地下载历史，也不声称浏览器能检查下载目录。ZIP README 写明范围和完整/未完整数量；缺正文或媒体的篇目明确标记。断开下载会停止后续篇目，临时目录最后清理。

## 开发合同与离线验收

`ArticlePreparation.identity` 由服务器内部适配器赋值，浏览器不能提交路径、正文、媒体或任意身份。缓存正文校验延迟到实际准备阶段，所以本地完整文件存在时当前数据库正文缺失仍可零媒体请求跳过。单篇 Wechat2RSS 工具仍只读取已授权缓存，媒体获取延后到本地预检查之后；不新增订阅或请求官方原文。

同进程串行化与本机独占锁在身份预检查前生效；跨进程正在保存返回明确 busy，失活进程锁可核实后恢复。发布仍按文章回执独占保留图片，使用 exclusive create 保护用户文件。新正文先记录发布日志，完成后原子建立正式回执；补齐回执采用临时文件与原子重命名，更新前核对回执未被外部修改。回滚仅删除当前请求创建的文件。

可复现命令（无平台访问，只有合成图片和临时目录/SQLite）：

```sh
pnpm --filter server exec jest article-incremental-export article-source-layout article-local-save article-export-images-pending article-export-scope article-date-filter article-local-layout feed-batch-selection-ui wechat2rss-single-download article-download.controller --runInBand
node --test scripts/feed-export-date-ui.test.cjs
pnpm --filter server exec tsc --noEmit
pnpm --filter web lint
pnpm --filter web build
pnpm --filter server build
```

核心验收覆盖重复 prepare/临时目录/媒体请求均0、不同目录、并发去重、只补缺失一图、正文编辑保留、旧未完整回执补入新图、失败回滚与重试、回执/身份/正文缺失/图片冲突拒绝，以及中断回执恢复。真实临时 SQLite 测试冻结25篇筛选、20篇分页的无漏无重、上海午夜边界、搜索和分组，以及两次独立完整快照和整号范围区别。测试最后比对库中原有记录，生产数据库未打开或修改。

本轮只交付代码与远端CI，PR保留草稿、开放、不合并；不重启生产服务，不进行真实全量下载，不扩展Rnote接入。测试不能代表已经对用户真实文章完成下载。
