# 增量文章归档与 ZIP 合同

本文描述当前 main 的本地缓存导出。README 的其余固定源码链接仍保留历史核对基线。

## 已实现

- 列表按当前公众号、分组、日期和搜索范围选文，冻结本轮 ID 集合；分批调用本地归档入口，单批最多 64 篇，正文每次最多读取 8 篇。
- 仅导出已缓存正文，不因导出自动请求平台补文。缺失正文、图片不完整和失败逐项返回，任务受理不代表文件齐全。
- 本地 Markdown 与图片保存到用户指定目录；已记录的文件身份用于后续归档。保留用户编辑，不能用“有回执”代替核对新增正文图片。
- ZIP 每次生成独立产物；解压不会自动同步用户已有目录或保护解压覆盖。
- 分别报告 Markdown、媒体完整性和缺图数量。打开 Markdown 和检查全部图片才算归档完整。

## 范围与限制

只覆盖库内已记录文章，不保证订阅前全部历史、付费全文或平台缺失媒体。新缓存图片仍需后续归档；未缓存正文应先通过已授权取文流程获取。云同步、双向笔记同步和自动覆盖用户编辑不属于此合同。
