# 订阅页浏览记忆

订阅页在本次浏览会话中记住日期、发布时间顺序、可用的阅读量／点赞量排序、关键词和分组。刷新页面或从工具页返回时，筛选仍显示在现有日期输入、排序下拉与关键词提示中。“清除筛选与浏览位置”一次恢复默认筛选、最新在前和首批列表；公众号仍以当前网址为准。勾选的下载／导出文章始终不恢复。

阅读缓存正文后回到打开前的列表位置。刷新列表时优先恢复可见文章及其相对位置，按需顺序读取本地已存列表分页；最多恢复10页、保留8个近期列表检查点，位置8小时后过期。文章被删除时退回可达到的附近位置，筛选无结果时显示既有空结果提示。关闭浏览会话后不承诺继续恢复；浏览器自身恢复旧标签时可能保留其会话存储。

“今天”“近7天”“本月”作为相对日期记住，以上海时间计算。刷新、重新回到页面、窗口获得焦点以及页面打开期间每分钟检查日期变化；上海跨日后更新范围。手动修改任一日期即改为固定日期，跨日不变。日期输入仍显示当前实际范围；清除日期保留其它筛选。

明确网址查询优先于记忆：查询中没有指定的筛选采用默认值，避免旧关键词隐藏新结果。网址指定公众号时不会继承旧分组。已删除分组回到全部，已删除公众号回到订阅首页。桌面启动仍进入订阅首页，浏览记忆不会跳转到工具页、自动打开文章或恢复正文 iframe 内的滚动。

浏览器禁用或写满存储时，筛选与阅读仍可使用；刷新后可以回到默认筛选。所有记忆只保存在当前标签的浏览器会话存储中，不上传、不修改文章或笔记。
