## 已实现

导出范围和保留编辑规则见[增量归档合同](../INCREMENTAL_ARTICLE_EXPORT.md)。来源框架见 [Provider 注册表](../../apps/server/src/collection/provider-registry.ts)。

按链接下载使用已有来源的可靠缓存和精确文章身份映射，不按标题猜测；等待队列或来源授权仍是外部条件。界面接线和来源配置必须按运行版本核对；不能因旧 README 描述就保证当前 main 有独立工具页面。当前 main 的本地阅读与导出可用，不自动请求缺失正文。单篇官方重试是另一个显式授权入口，见[单篇重试](../SINGLE_ARTICLE_BODY_RETRY.md)。
