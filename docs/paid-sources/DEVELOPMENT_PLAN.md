## 工时口径修正：最小接入与扩展范围分开

此前父线程提供的付费整体估算为 **25–42h，按每日6h约5–7个工作日**。本轮最初的54–78h/9–13天把持久任务恢复、离线云端全文副本、编辑版本保留和扩展异常矩阵一起计入必做，扩大了首期范围；它不应替代此前同范围估算。这里只修正技术开发计划，不修改用户审批的费用预算报告。

本次新核到的代码缺口是：已注册 native discovery 会优先取得新增请求，已保存刷新来源也优先于 env；小红书尚无独立模型/adapter，媒体与导出仍为微信语义；Sites 尚无本机通信桥。这些接缝原本就属于付费接入工作，不构成额外几天的“新风险费”。Docker/WSL 缺失属于安装及用户操作条件，不重复计算为完整开发阶段。

## 供应商邮件的最小确认项

用户已经发邮件；本轮不代发、不重复索要秘密。B 回复只需核：

1. 包内是否已经有目标博主的公开发布列表、真实分页和图文详情，给当前接口文档与脱敏成功样例；不是仅签名、搜索或商业笔记指标。
2. 返回真实作者/笔记身份、发表时间、完整文字、全部图片及图序；哪些内容类型、历史和地区不可用。
3. 运行是否依赖付费 API、授权服务器、代理/账号、续费或其它服务；源码能否在普通本机环境构建启动。
4. 私人图文归档用途是否获许可；后续平台变更如何维护、更新范围/周期/费用是什么。

A 需当前 OpenAPI/实样与单价/限流，不把 B 的承诺套给 A。公众号需当前授权及真实实例，不因为旧 Provider 已写就直接打开全库来源。
