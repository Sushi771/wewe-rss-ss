手机将作者列表收为可关闭抽屉，内容页使用单列阅读，图片按原顺序；电脑用作者列表＋内容列表/阅读区。主要操作在小屏可见，弹窗内部可滚动，底部确认/取消可达；键盘焦点、Escape 和状态文字须验收。当前文档 HTML 是阅读总览，不是这个产品原型或视觉验收。

## “更新全部”

1. 打开确认面板，列出本次启用作者、预计请求范围和预算限制；没有可用来源时给出具体原因。
2. 确认后使用一个幂等键提交批次。前端按钮防抖，服务端仍需防重复；刷新页面或换设备不生成第二个上游任务。
3. 显示排队、读取列表、读取正文、归档图片、等待上游、已结束各阶段；读状态只查询本次任务。
4. 分别显示“新增”“补全”“无新增”“读取缓存”“等待上游”“正文/图片未完整”“认证/限制/余额不足”“来源未配置”。“结束”不统一改成“成功”。
5. 用户可以停止未开始的作者；已经发出的请求显示“等待当前请求结束”，不能声称已撤回或自动补跑。

Wechat2RSS 的异步受理不能显示“文章已更新”；其缓存有内容也未必是本次新抓取。小红书列表分页触及预算显示窗口未完成。一个作者失败不清空其他作者的成功结果；对同一共享账号/供应商的认证或计费拒绝应暂停该组，不反复提交其他作者。

本机离线：更新按钮禁用，显示“请先启动本机服务”。可阅读已同步缓存及其时间；不静默排队等待电脑恢复。执行中断：保留任务编号和已完成项，状态未知时不自动重试。预算未设定：显示可配置原因，不能默认无限付费请求。

## 添加和切换来源

选择“公众号”后使用公开文章链接进入已有来源发现；选择“小红书”后使用公开博主主页/稳定身份进入独立确认。短链只作输入候选，无法核身份时明确未添加，不按昵称猜身份。没有可用接口时保留输入，提示“等待来源配置”，避免重复收费提交。

用户明确选择来源后，后端核能力；现有 native discovery 优先级不能被前端隐藏。切换原有公众号到 Wechat2RSS 的页面展示旧来源、新来源、身份核对及历史保留说明；真实验证后显式切换，失败保持原绑定，不删除旧停止状态。小红书 A/B 使用一个确定来源，不在失败后自动换另一套付费来源。

API Key、Wechat2RSS 激活信息和平台账号授权只在本机私有配置/供应商正常管理页完成，不放入 Sites 浏览器输入框、localStorage 或打包资源。

## 阅读与归档

全文由已归档内容渲染，不允许上游 HTML 脚本或任意 iframe 执行。小红书图文保留段落、换行和图片顺序，不抓评论或推荐内容。缺正文/图片时展示真实缺口与原公开链接，仍可读旧版本；不把摘要显示为全文。

Sites 的“下载离线包”保存到当前浏览器设备，返回真实下载响应，不返回本机绝对路径。原本机“保存到 Obsidian”继续写用户已有目录；跨端界面不得声称能写手机/另一电脑的 vault。只有取得可核验的缓存正文和图片后，导出无需再请求平台；未缓存项目不触发隐藏补抓。

| 场景                | 预期表现                       | 开发期可验证          | 上线后必须验证               |
| ------------------- | ------------------------------ | --------------------- | ---------------------------- |

| 缺图/视频笔记       | 不列为完整图文                 | 合成图文状态          | 代表真实笔记与图片打开       |

本轮已本地接原添加公众号窗口：默认来源行为保留；显式选择 native/Wechat2RSS，未就绪显示原因并禁止确认。选择切换保留链接/账号、清旧来源提示；请求期间不允许重复提交/切换/重开。取消等当前请求结束后保留未处理链接，晚到结果不弹旧来源成功或失败通知；关闭再打开保留选择。来源失败不静默回退，机器错误码转为可读提示。

账号查询区分新增和原 native 修复：选择付费来源不会影响修复窗口取正常账号。实际事件处理器离线回归已通过；没有 Sites 站点、部署或真实浏览器视觉验收。

## 已交付的隔离跨端原型

使用现有 React/NextUI 按钮、复选框、弹窗和样式，独立入口不注册 App 或 tRPC。手机用订阅抽屉和单列阅读，桌面保留作者侧栏；可筛平台、选示例作者、演示列表/正文/图片进度，以及未就绪、待验证、失败、完成与取消。所有内容虚构，真实更新/下载禁用，始终显示本机未连接。原型的暂停/重复点击/来源隔离由实际内存模型回归覆盖；该离线原型尚未独立视觉验收；正式本机页面的隔离Edge结果另列。

构建 `node scripts/build-paid-prototype.cjs`，再用 `node scripts/build-paid-plan-review.cjs` 合并到一个可打开的本地总览。它不是 Sites 应用、连接桥、持久任务或真实图片保存。
