# 小红书订阅产品说明

> 状态：2026-10-24 开发设计初稿；尚待集成实现校准与验收。基线为 `f609bda0334f17f6c28ff84020d31cd5c47f3417`。本文的目标行为不代表真实来源已接通、用户路径已通过或已部署。

## 用户目标与范围

用户可以输入一条小红书笔记链接或博主主页链接，识别作者并核对信息后订阅；订阅成功后更新笔记列表，选择需要的笔记批量下载正文和图片，保存到本机，后续更新和重复下载增量去重。

首版覆盖图文笔记。视频、评论、私信、发布不在本轮范围。既有公众号订阅、分组、保存偏好和归档继续复用；不另建一套下载目录系统。独立单篇工具保持独立，不能用其成功代替博主订阅验收。

## 适用内容管理功能对照

用户明确要求保留公众号已开发的全部适用内容管理功能。下表根据指定基线代码核对，目标列属于本轮要求，完成状态须由集成测试回填；不能因新增订阅流程删除原搜索、分组、导出或批量操作。

| 能力 | 公众号既有行为 | 小红书基线与本轮目标 |
| --- | --- | --- |
| 搜索 | 标题、发布者及已缓存可见正文，提示正文覆盖缺口 | 基线仅当前博主标题搜索；补齐适用的作者/缓存正文搜索并如实说明覆盖范围，不为搜索自动取全文 |
| 日期筛选/选择 | 上海时间单日、起止日期、今天/近7天/本月 | 基线未接日期筛选；复用日期组件与边界，按可信笔记发布时间筛选并选择 |

| 批量选择 | 单选、全选已加载；筛选变化清理选择，完整筛选范围另行冻结 | 基线已有可见完整缓存笔记勾选；保留并让新图文可进入下载，明确已加载与当前筛选全部范围 |

| 内容阅读 | 展开正文和图片 | 保留小红书已有正文/缓存图阅读，与列表元数据区分 |
| 本机保存 | 原目录偏好、选中保存、完整筛选保存、回执增量保护 | 保留并补齐适用范围；选中下载与已有缓存导出分清，冻结目标后再处理 |

## 主流程

1. 在“小红书”的新增入口粘贴笔记或主页链接，点击识别。
2. 展示服务端确认的作者名称、主页、可选头像和已有订阅提示；用户可选择现有小红书分组。笔记输入识别的是该笔记作者，不把输入笔记直接等同为订阅。
3. 用户点击“确认订阅”。仅此时创建或复用本地博主；取消确认不新增订阅、不更新列表、不下载内容。
4. 订阅成功后可更新该博主的笔记列表。列表更新仅取得笔记元数据，不隐含全文或图片下载。
5. 用户勾选图文笔记，核对数量和本机保存目录后点击批量下载；后台逐项取得并核验完整正文和图片，再复用原保存器落盘。
6. 后续再次更新列表只补新增身份；重复下载跳过已有完整文件，缺失或失败内容按真实回执处理。已有正文和用户文件不得被空值或不完整内容覆盖。

## 成功口径

| 阶段 | 对用户承诺 | 不可据此推定 |
| --- | --- | --- |
| 作者已识别 | 输入链接已绑定可信作者，等待用户确认 | 已订阅、列表可用 |
| 订阅成功 | 本地博主已创建或复用，返回 `subscribed:true` | 已取得任何正文或文件 |
| 列表更新完成 | 本次有界列表任务完成，可选择返回的笔记 | 全历史完整、正文已下载 |
| 下载任务完成 | 本次选中项已按回执保存或确认为可跳过 | 未选中项或其他设备已有归档 |
| 图文保存成功 | 正文和要求的全部图片实际写入本机，可离线打开 | 平台永久可用、未来增量已验收 |

## 约束与失败体验

- 同一上游作者重复识别、重复确认应复用同一本地博主；名称不是去重依据。旧待接入博主与可信作者的关联必须经服务端核验，不能仅凭昵称合并。
- 解析身份有有效期，过期后重新识别；不能让浏览器提交作者 ID 或自行修改确认结果。
- 来源未配置、登录失效、访问限制、未知回执、网络或媒体失败均显示具体状态；不伪造作者、笔记、完成数或进度，不自动绕过限制。
- 更新列表和下载是两个操作。批量下载只处理用户本次选定且属于当前博主的笔记，不将“全选当前列表”扩大成全部历史。
- 取消后保留已提交的列表或已成功保存的文件；明确剩余数量。关闭提示不等于取消任务。
- 保存沿用原目录选择、记住目录和每次询问选项。本机直存仅适用于既有本地访问能力，不承诺远端服务器可直接写用户电脑。
- 分组只改变应用分类，不移动既有下载文件，不重建订阅身份。

## 本轮交付边界

当前开发只使用合成作者、笔记、图片和隔离数据库/输出目录测试。真实扩大采集、实际凭据接入与生产部署仍待确认；历史文档中的旧授权或验收结果不扩展本轮范围。GitHub 同步与 draft PR 由主负责人集成后统一处理。

### 订阅界面一致性

公众号与小红书使用同一套订阅控件。新博主确认订阅成功后读取笔记列表，用户再选择内容下载；已订阅博主重复确认只定位已有订阅。已缓存视频保留导出能力。
