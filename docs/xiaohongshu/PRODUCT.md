# 小红书订阅产品说明

2026-10-24 按集成源码 `a249be1` 及最终聚焦修复校准。基础流程及内容管理已通过合成测试；验证范围与遗留项见 [验收记录](ACCEPTANCE.md)。

## 用户目标与流程

输入小红书笔记链接或博主主页链接，识别作者并确认订阅；随后更新列表，选择图文笔记下载正文图片到本机，后续更新及重复保存增量去重。首版新下载以图文为主，既有完整视频缓存仍可导出；评论、私信和发布不在范围内。

1. 从“小红书”的“+”入口输入链接，识别后显示作者名称、主页、可选头像和已有订阅提示。
2. 确认作者及小红书分组后订阅。取消或修改输入不创建订阅；确认使用短期服务端解析身份。
3. 新订阅成功后界面启动一次列表任务，重复订阅只定位已有博主。列表更新只读元数据，不下载正文或图片。
4. 选择图文并使用原目录设置下载保存；“选择当前筛选全部”可覆盖未展开的匹配记录，“全选已加载”仅勾选当前显示行。
5. 再次更新保留旧笔记及完整正文。下载重复项沿原保存回执处理，取消或失败保留成功项，可显式续跑剩余工作。

## 适用内容管理功能对照

| 能力 | 当前小红书实现 | 与公众号的差异或待补项 |
| --- | --- | --- |
| 搜索 | 全部/分组/当前博主内匹配标题、作者及已有正文可见文本 | 不自动取文；缺失正文只参与已有字段搜索，页面提示覆盖范围 |
| 日期筛选 | 复用上海时间单日、起止日、今天/近7天/本月及非法日期校验 | 未知发布时间不纳入日期范围 |
| 分组 | 保留创建、改名、排序、拖动、批量移动及未分组 | 分类不移动文件，平台分组隔离 |
| 批量选择 | 加载更多后保留早先选择；可选择当前筛选全部 | 改搜索、日期、排序或博主清空选择；新展开行不自动被选中 |
| 排序与浏览 | 发布时间正/倒序；首次20条，每次追加20条 | 后端 `notes` 仍全量查询，追加只是客户端渲染；无阅读/点赞排序 |
| 内容阅读 | 保留缓存正文、图片和既有完整视频缓存 | 列表元数据不等于已取得全文 |
| 本机保存 | 原目录、每次询问、图文选中下载及重复回执保护 | 当前筛选全部可先选择再下载；没有单独的整博主本机保存范围按钮 |
| ZIP导出 | 已选完整归档、当前筛选全部、全部或本博主全部；按作者及每100篇分包 | 只导出完整缓存；全部忽略搜索/日期/分组，选中作者时仍限该作者。单包仍受25MB缓存预算限制 |
| 进度、取消与续跑 | 列表/下载任务独立；真实计数、取消、显式续跑 | ZIP为前端分批流程，取消停止后续包，不提供后台ZIP续跑 |
| 来源专属功能 | 小红书稳定作者/笔记身份独立保存 | 微信账号、RSS/OPML、热度字段不直接套用；不宣称小红书已支持 |

两平台共用 `SubscriptionPrimitives.tsx` 的工具栏、搜索、更多菜单、订阅弹窗、排序、选择栏和进度；日期与分组继续复用原组件。

## 成功与失败口径

作者已识别表示等待确认；`subscribed:true` 表示本地订阅建立或复用，不表示已有正文。列表任务持续按上游游标枚举到结束或停止，完成仅指本次来源枚举结束，不证明平台全历史无遗漏。图文保存成功需正文及所需图片实际落盘；缓存完整、ZIP生成和浏览器触发下载分别记录。

同一作者按稳定身份复用本地博主，不能按昵称合并。显式传入有效分组会更新已有博主分组，省略则保留旧分组。来源限制或失败停止后续详情请求，不自动绕过；取消不删除已保存内容。任务恢复需要用户操作，不会在重启时自动重新采集。
