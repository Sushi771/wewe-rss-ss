# 小红书订阅交互设计

> 状态：开发设计初稿，尚待实际 UI 与接口集成校准。下述行为均需按 [验收矩阵](ACCEPTANCE.md)验证，不作为已验收记录。

## 入口与页面结构

沿用 `/dash/xiaohongshu`、当前登录保护、博主侧栏、平台分组和笔记列表；新增入口继续放在“+”窗口。复用项目已有 NextUI、sonner 与管理组件，遵循 [前端开发原则](../UI_DEVELOPMENT_PRINCIPLES.md)，不为本轮新增通用组件框架。

新增窗口分为“输入链接”和“确认作者”两个阶段。输入框说明支持笔记或博主主页链接；具体长短链格式以实际解析器校准，不承诺未实现的格式。识别时显示等待状态并防止重复提交。修改链接后立即丢弃旧解析结果，确认按钮只能提交当前链接对应且未过期的 `resolutionId`。

确认页显示作者名称、主页链接、可选头像和“已订阅”提示，使用原小红书分组选择器。用户可以返回修改、取消或确认订阅。头像缺失不阻断已核实身份；不能用占位作者冒充识别成功。确认成功后选中返回的 `creatorId` 并刷新本地博主列表。已有订阅复用原记录，分组变更语义以实现校准，不悄悄移动已有博主。

## 操作与反馈

| 区域 | 主操作 | 反馈与边界 |
| --- | --- | --- |
| 博主信息 | 更新笔记列表 | 显示列表任务状态；不下载正文图片 |
| 笔记列表 | 勾选图文笔记、批量下载 | 显示选中数量；提交冻结的博主和笔记 ID 集合 |
| 保存偏好 | 原目录选择、记住目录、每次询问 | 复用原设置与 `pickToken`，不提交任意文件路径 |
| 任务反馈 | 状态、数量、取消 | 列表与下载使用不同标签；只显示后台真实进度 |
| 结果反馈 | 已完成、跳过、失败、剩余 | 部分成功与被阻挡有明确原因，不合并成全部成功 |

列表中的元数据、已缓存全文和本机文件是不同状态。新发现的图文笔记须允许进入显式下载流程，不能沿用“只有 `status=complete` 才可选”而使未下载笔记无法选择。视频项说明首版不支持本次下载，不计作图文保存成功。原有缓存仍可按原能力阅读或保存，其成功不能证明新来源已接通。

## 搜索、日期、批选和导出

按 [功能对照](PRODUCT.md#适用内容管理功能对照)保留原工具栏能力，复用 `ArticleDateFilter` 及日期选择工具。日期按上海时间的原文/笔记发布时间，开始日含 00:00，结束日含当日且不含次日 00:00；未知时间不纳入日期范围。提供单日、起止日期及现有快捷范围，非法或倒置日期明确阻止操作。

搜索覆盖标题、作者和已缓存可见正文；缺少正文时说明结果范围，不自动下载正文来扩大搜索。搜索与日期、博主/分组共同约束结果。时间顺/逆序改变展示顺序，不改变范围成员；没有可信热度字段时不显示伪造排序项。

“全选已加载”只选已展示的匹配项，新增加载的行不自动被选中；筛选变更清理旧选择。选中下载、选中缓存导出、当前筛选全部和整博主导出必须标明各自范围。完整筛选导出使用服务端冻结 ID 集合，不能只导出当前页；整博主导出须明确忽略搜索/日期筛选。保留已有 ZIP 和本机保存入口，不强制用户改用另一种格式。计数、上限和尚无正文/媒体的项均如实提示。

## 选择与异步归属

- 切换博主清空选中笔记和当前正文；进行中的任务保留其原 `creatorId` 归属。其他博主的完成回执不得覆盖当前页面。
- 搜索、刷新和列表变化后核对选中 ID 仍属于当前博主；批量提交使用一次冻结的目标集合。隐藏项的选择语义应在界面明确，不能扩大下载范围。
- 同一操作进行中禁用重复按钮；服务端仍须处理冲突及幂等，不能只靠按钮禁用。
- 进度未知时显示等待及实际计数，不计算虚假百分比。列表总量是本次有界窗口，不显示为博主全历史总量。
- 提示按任务和状态转换去重。正常结束可短暂反馈后收起，不新增常驻任务历史页面；保留足够信息供本轮结果核对。

## 状态与取消

任务统一显示 `queued`、`running`、`completed`、`partial`、`blocked`、`cancelled`、`failed` 对应的中文文案；终态由后台给出。`partial` 展示已处理与剩余，`blocked` 展示限制原因并停止自动尝试，`failed` 展示失败原因。

取消调用 `cancelTask`，受理不等于任务立即终止；直到后台终态返回前显示“正在取消”。取消不回滚已保存文件，不删除已有缓存。当前项是否已提交必须由后台真实回执决定，界面不能自行将它算作取消或成功。目录选择取消与任务取消均保留已有文件，并给出可理解结果。

## 窄屏和键盘验收

保持现有手机侧栏默认收起、顶部切换和展开管理；新增窗口、作者卡、分组选择和结果区不产生横向溢出。沿用组件库的焦点管理，验证 Tab、Enter、Escape、返回、关闭与重新打开，不将组件测试替身称为浏览器或原生目录对话框验收。

布局验收至少覆盖既有桌面和约 390px 手机宽度；具体截图与真实点击结果留待集成验证。接口与保存架构见 [TECHNICAL](TECHNICAL.md)。
