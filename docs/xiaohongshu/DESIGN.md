# 小红书订阅交互设计

本文对应集成源码 `e962a5b38fe8281ee29814915370b476ede7140e`。合成浏览器与自动化结果见 [验收记录](ACCEPTANCE.md)。

## 入口与共享组件

沿用 `/dash/xiaohongshu`、登录保护、博主侧栏、分组及笔记正文区。“+”窗口分输入链接、确认作者两阶段；修改输入丢弃旧解析结果。头像可缺省，不能用占位作者冒充识别成功。确认可选择现有小红书分组，显示已有订阅提示。

公众号与小红书复用 `SubscriptionPrimitives.tsx` 的工具栏、搜索开关、更多菜单、订阅弹窗、排序、列表选择栏和进度组件；日期与分组沿用 `ArticleDateFilter`、`ManagementFolders`。低频来源说明和保存设置默认收起，进度位于工具栏上方。遵循 [前端原则](../UI_DEVELOPMENT_PRINCIPLES.md)，业务请求仍由各平台页面承担。

新博主确认后启动一次列表任务；已订阅者重复确认只定位原博主。服务端显式收到 `groupId` 时可移动分组，未传则保留。列表更新与下载有独立按钮和任务文案，未下载图文可以勾选；未缓存视频不进入新图文下载，既有完整视频缓存保留ZIP能力。

## 搜索、日期和选择

搜索当前实现是标题及缓存HTML子串匹配；尚无作者匹配和可见正文正规化。搜索不自动读取全文。日期按上海自然日：开始含00:00，结束不含次日00:00；未知日期不纳入范围。复用单日、起止日和快捷选项，非法范围阻止操作。

发布时间可正/倒序，同时间以ID稳定排序，未知时间置后。后端一次返回全部匹配元数据，页面先显示20条，再每次追加20条；“加载更多”不是服务端分页。

“全选已加载”只作用于已显示可选行，勾选或取消只修改这些ID，保留其他已选行；展开新行不自动选中。另有“选择当前筛选全部”。下载取完整选中集合，不截到已显示20条。搜索、日期、排序和博主变化清空选择；切换博主同时清理原正文和终态进度。

## 下载与ZIP范围

下载沿原目录选择、记住目录及每次询问设置，提交当前博主及冻结的选中图文ID。重复点击由按钮状态和后端互斥共同保护。

ZIP弹窗提供“已选完整归档”“当前筛选全部”“本博主全部（忽略搜索及日期）”。后两者重新查询匹配元数据后在前端冻结完整缓存ID，不受已渲染行数限制；这不是服务端持久快照。每100篇串行生成一包，文件名标注part编号；单包超过原25MB预算时明确失败，不截断。205篇合成浏览器验收生成100/100/5三批。

ZIP取消或回执未知停止后续包，不盲目重发当前包。界面计数表示已生成并触发浏览器下载的包内篇数，不证明浏览器最终已保存文件。需按实际ZIP内容另核归档结果。

## 任务进度、取消和续跑

列表和下载分别显示 `queued/running/completed/partial/blocked/cancelled/failed`，数量来自后台，不以跳过或失败冒充新增保存；列表尚未枚举的总量未知，不显示虚假全历史百分比。

任务可收起；关闭进度不取消任务。取消后后台停止后续工作，当前原子保存可以完成。终态尚未释放执行器时仍轮询，不能提前续跑；`resumable:true` 后提供续跑按钮，以原任务ID发起并切换新任务ID。下载续跑复用原目录，目录改变则拒绝。已完成和跳过项不重做。

轮询由任务ID驱动，用ref访问客户端工具；终态停止轮询，避免工具包装对象随渲染变化而重启effect、清掉用户新选择。任务回执绑定博主，切换后不得污染当前视图。

## 布局与交互验证边界

已报告的合成浏览器检查包括两种输入确认、列表任务、取消/收起、终态后新选择、搜索清空选择和390px无横向溢出，以及205篇三批ZIP。原生目录对话框、全部键盘路径和真实账号链路不由这些结果代替，后续按 [验收记录](ACCEPTANCE.md)补齐。
