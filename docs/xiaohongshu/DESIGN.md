# 小红书订阅交互设计

沿既有订阅、列表、任务和目录保存流程改进，不增加新的管理层级。产品边界见[PRODUCT](PRODUCT.md)。

## 前端与任务状态

标题使用同稳定身份的原文链接；显式准备/重新准备的临时链接只驻留内存，切换作者/笔记或关闭后不能被迟到响应串用。普通页面加载/状态重读不触发来源请求。公众号和小红书均无正文阅读入口，下载内容在本地阅读。

列表保留未缓存目录项，展示已存四指标；缺字段与非精确数显示未知，真实0保留，快照时间可追溯。头像缺失不伪造，未知关注隐藏。筛选/排序先覆盖全部匹配记录，分页后选集、导出范围和queryVersion保持一致；数据变化不悄悄替换选集。

整号清单分别呈现目录、正文/媒体、指标及本地保存阶段。阶段额度为0就停在边界；目录停点不能创建下载任务。累计阶段上限和任务总额独立调整，调整后仍paused，另行明确继续；pending/unknown不显示可绕开的扩额或续跑入口。取消只停止后续工作，已有原子提交和用户文件保留；重新进入按原任务读状态，不用再次提交代替找回。

未知派发回执与已知来源拒绝分开提示。媒体HTTP状态仅当实际观察到时展示固定数值码，普通网络失败不猜成拒绝；不展示签名URL或异常正文。恢复会话不等于风险解除。评论正文/回复入口暂停，历史数据不删除。

## 下载与布局验收

主流程为Markdown、相对image/及已核验视频的video/，独立回执表示正文媒体、附页新增/复用/冲突及失败；正文skipped不代表附页已更新。重复保存保护手改正文与附件，ZIP触发下载不等于文件已落盘。

用编译后页面和合成数据覆盖窄/宽屏、矮窗、缩放、sticky表头、键盘焦点/遮罩、取消和迟到响应；同时核DOM、点击目标与截图，不能仅用“无横滚”判可用。使用Playwright或项目既有等效浏览器工具；没有实际执行就记待验证，不以静态渲染冒充浏览器或Obsidian阅读。按[ACCEPTANCE](ACCEPTANCE.md)核对证据。
