# 小红书笔记组合筛选

展开“笔记数值筛选”后可添加多个点赞、收藏、分享或评论数量条件。比较方式包括严格大于、大于等于、严格小于、小于等于和包含上下限的区间；允许同一指标出现多次。默认“全部满足（AND）”，也可切换“任一满足（OR）”。没有条件时不筛选。缺失值不视为 0，也不满足任何数值条件；OR 中其他已知指标满足条件时仍可匹配。

输入非负有限数值，不含单位且不超过安全数值范围；空值、负数和反向区间会显示提示，并暂停显示匹配结果。可以逐行删除或清空全部条件。原有博主、分组、时间和搜索范围先应用，再对完整范围做组合筛选，最后使用现有三态排序和列表分页。修改条件会清空勾选并回到首批结果，但保留当前排序。

“导出当前筛选”固定当前条件，对重新读取的本地范围应用同一规则，再导出明确的笔记 ID；“导出全部”忽略组合条件。没有改变导出接口、来源预算、评论采集或原文准备行为。条件操作只使用本地已保存的数量，不采集或刷新小红书数据；评论正文仍不在平台展示。

维护约束：73761 的 notes 接口不传 limit 时返回完整匹配集合；前端不传 limit/offset。若未来改为服务端强制分页，必须在后端分页前应用同样的组合条件和排序，不能只筛已经加载的页面。对应回归为 `scripts/xhs-combined-filter.test.cjs`、`scripts/xhs-combined-filter-browser.test.cjs` 及订阅 UI 中的筛选导出用例；已接入现有离线 CI。
