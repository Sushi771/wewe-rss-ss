# 小红书订阅验收

本页定义可复验的判据和测试入口，不代替运行回执。版本、交付状态及当前CI/构建缺口见[开发维护](DEVELOPMENT.md#本次交付状态2026-10-28)。历史通过只适用于其输入与版本，不累计测试总数宣称全部完成。

## 按变更选择验收

每次记录最终SHA、受影响合同、原始输入/产物身份、命令/环境、退出码与未执行项。重跑受影响合同及必要共享回归；字节与前置条件未变、仍有效的证据可复用。文档修订核链接、口径与diff，不因此执行来源请求、生产恢复或全套故障注入。

代码测试、包运行、实际安装、真实来源和Obsidian阅读分别判定。浏览器触发下载、HTTP200、健康页或保存器自身成功回执均不能单独证明最终结果。没有对应证据时写待验证。

## 原始材料与独立判定

| 受影响合同 | 从哪些原件开始 | 独立oracle与边界 |
| --- | --- | --- |
| 作者、分页与指标 | 获准原响应结构、请求/游标关联、SQLite稳定ID集合 | 手工核实的身份及字段期望；不调用被测mapper生成expected。0与未知分开；请求30返回32应保留全部合法条目，61条整页拒绝。列表结束不证明平台全史 |
| 正文与媒体 | 原正文、原图有序字节清单、实际Markdown及附件 | 段落/字符/标点/顺序保留，只允许转义与空白规范化；独立解码、内容hash与有序引用分别检查，不以同图数代替 |
| 任务与恢复 | SQLite原始行、故障时间线、实际transport调用、文件bytes/mtime | 独立连接读检查点、额度与pending；验证不重放及非目标数据保留。丢失的旧响应不能由新诊断重建 |
| 构建与安装 | 固定源码/lockfile、完整包manifest、实际进程及服务资源 | 检查源码到产物配对和运行JS/CSS；包含时间戳时声明比较规则，不伪称逐字节可重现。安装前后的数据兼容另验 |
| UI与本地阅读 | 最终编译页面、真实事件/DOM、实际目录及用户文件 | 事件、截图与选集断言互相核对；静态HTML不能证明点击、焦点或文件落盘，浏览器Markdown截图不能替代Obsidian |

真实身份、token、原响应、私人内容及本机审计留在获准私有证据区；公开夹具用合成字节和独立期望。第三位维护者应能按固定SHA和命令重现失败与修复结果。公开源码与合成测试入口见[开发维护](DEVELOPMENT.md)；具体安装/失败原件只在私有材料中交接，不另建平行报告体系。

## 任务、保存与恢复反例

按受影响合同选取下表，不要求每次发布重复执行全部场景。

| 编号 | 反例 | 必须观察到 / 独立检查 |
| --- | --- | --- |
| D01 | 提交任务后刷新页面，一次查询失败 | 找回原任务、博主与冻结范围；重进仅查询，明确继续才派发；浏览器事件、请求次数与SQLite交叉核对 |
| D02 | run finally的终态persist失败 | pending/controller释放；未确认持久状态不显示成功、不隐式重放；独立读行和后续同作者准入 |
| D03 | COMMIT成功但应答丢失、迟到前驱 | 同一后继，不重复保存；未知仍阻挡；等待执行lane后核lost=true、saves=1、持久completed和pending=0，不以sleep掩盖竞态 |
| D04 | 收尾、取消、并发继续、新选择 | 普通迟到保存不能覆盖cancelled；明确继续CAS只能消费一次；收尾不能继续，旧返回不能污染新选择 |
| D05 | 删段、换段序、改标点，仅转义/空白变化 | 前三者失败，最后一类可相等；实际缓存准备和原保存器产物与独立期望比较 |
| D06 | 图数不变但换图/换序、坏图/丢文件、手改正文/附页 | 身份、顺序、解码分别失败；重复保存保留手改bytes和mtime，同版复用、冲突版本及失败回执可核 |
| D07 | 声明构建输入缺辅助脚本、包装或SQL | 缺项明确失败，不从运行目录补件；源码/构建/迁移配对，未知schema拒绝。方法见[发布复现](../RELEASE_REPRODUCIBILITY.md) |
| D08 | 受影响恢复路径在合成库上中断、重启与回退 | 独立SQLite完整性/外键/业务行、unknown及文件对账；候选与回退实际启动、退出，无真实出站。有效恢复证据未变时不重复复制整库 |

已有入口：`apps/server/src/collection/xhs-subscription.spec.ts`、`xhs-whole-creator.spec.ts`、`xhs-whole-source-fence.spec.ts`、`saved-media-writeback.spec.ts`及对应transport/media诊断spec。使用真实临时SQLite、原保存器和注入transport；HTTP联调复用实际tRPC路由及前端恢复助手，避免两个Mock自证。

有界列表回归核前端传maxPages=2、两页成员和游标同事务保存、仍有后续时停在页数上限、显式继续沿旧游标；全部skip且终态确认后不创建空后继。真正未知、失败项、取消、后续游标的负例保留。`connectionStatus.requestAttempts`仅在同一实例内比较，不证明媒体已保存。

整号预算/派发变更时覆盖：作者隔离，阶段零额度停点，资料/列表/详情/媒体实际计账，共享/任务累计额度，扩额仍paused且原使用量/时间窗不变；取消前零派发、派发后未知栅栏不重放。涉及持久间隔时用隔离时钟验证资料与列表顺序、等待中取消及实际间隔；不把它扩为无关文档或布局修改的必测项。

历史评论回归仅证明兼容和防覆盖。`xhs-engagement.spec.ts`的20001条合成分段须核唯一集合、每段预算、索引/附页实际落地与复用；不能称当前任务采集评论或证明平台完整。未核实的视频详情合同保持待补。

## 原文链接与浏览器

来源合同以已固定的官方PC源码/样例为外部oracle，记录内容hash及提取位置；不可用被测URL helper产生expected。若没有该原件，真实合同保持待核。

| 反例 | 判据 |
| --- | --- |
| 同作者同名笔记、前导0、错作者/错note | 按稳定字符串ID绑定；不移用其他笔记token |
| 安全来源URL、白名单query、显式source与锚点 | 保留合法语义；只接受精确`#comment-section`；外域、userinfo、危险协议和编码绕过拒绝；pc_user仅用于有证据的作者上下文 |
| 内存命中、冷恢复、无预算/预算耗尽 | 命中增量0请求；冷恢复逐请求预记账；不新建点击预算、不退款、不清stopCode或自动重试；旧paused历史与当前来源拒绝分开判断 |
| 连点、切换作者/笔记、关闭后迟到 | 同步去重；旧响应不导航、不污染新选择；用编译客户端的实际事件和导航拦截核对 |
| 合成token经过成功/错误路径 | 分别捕获logger、error、SQL、任务document与文件写入；不得只查最终DTO。临时URL不落持久存储；Markdown单canonical链接无访问参数 |
| 来源错误、预算错误交错 | 固定停止码准确，未知保留；不换入口或重置账本 |

页面浏览/状态重读不触发来源请求。缓存、未缓存目录及视频的原文准备不依赖body-ready；公众号与小红书无平台正文阅读入口。共享`article.byId`的受保护Sites下载路径仍保留，不为删除界面而删缓存或用户文件。

受影响布局用最终编译产物验证窄/宽屏、矮窗和缩放，包含长标题、极大数、0/未知、空态、任务展开/收起和模态。可复用320/390/790/1024/1580宽夹具；截图配真实点击、滚轮、Escape/焦点、选集和迟到响应断言，不仅检查无横滚。已有静态渲染测试用于快速状态检查，不替代浏览器。

真实PC原文可读性按单独获准范围验证目标笔记；popup创建或HTTP200不足以证明。Obsidian验收检查实际Markdown、相对图片、长图/横图和窗口缩放；目录保存回执与ZIP中央目录、选集、正文/媒体各自核对，不能互代。先复用仍有效的获准材料，缺证据记待验，不自动重采。

`recoverSingleNote`及明确追加尝试另验作者/note、过期、一次性/并发/重启、共享预算、拒绝停止、历史风险保留、disabled作者及pending媒体；无列表/评论/媒体请求、无后台任务。无query的来源路径及指纹不证明图片完整或可重放。

## 维护变更的附加验收

仅在备份/退役覆盖逻辑受影响时运行`python -m unittest discover -s apps/server/scripts -p test_snapshot_covers.py`及`test_indexed_retirement.py`：仅既定普通运行列可豁免，正文/媒体/has_history/未知字段/类型/schema及非自包含引用拒绝；覆盖验证时间绑定同一路径和SHA，不能转记到旧恢复点。这些只读测试不执行生产退役或取得删除授权。

存储状态UI受影响时核现有`/startup-status`快照：3 normal＋1 pending策略及生成/验证/覆盖时间分开；无owner显示不可用，读取不扫描备份、不申请写许可。展示不代表轮换执行成功。

## 通过与停止

本次发布需最终包完整、所选必需检查通过且无未解释跳过，旧数据/unknown/用户文件保留，实际运行身份、active、端口及JS/CSS与manifest一致；对应用户路径另有持久结果。真实来源或Obsidian未执行时不得由合成绿灯补记通过。

目标身份/写入边界不明、必需查询被拒、ledger/adopted不一致、未知owner/claim、包/迁移不匹配、容量不足、回退失败或来源拒绝时停止对应动作，保留错误及回执。不删锁/journal、不清unknown、不伪造policy/ledger、不反复换工具重试。项目自建检查若过强，先用真实反例修正适用性；实际访问拒绝须按权限处理。达到约定验收即交付，不继续扩建机制。
