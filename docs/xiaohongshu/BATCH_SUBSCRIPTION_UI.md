# 批量订阅界面

在小红书订阅栏选择“批量订阅”，一次粘贴多条官方链接或完整分享文案，选择归属文件夹后提交。预览只统计初步识别的链接与完全相同的重复项；最终官方格式验证、按博主去重和订阅结果以服务端逐项回执为准。一次最多 100 条候选链接、65536 字符。

此操作只订阅博主，不自动采集笔记或评论。队列使用既有共享来源额度、限速和风险闸；界面不会在打开时提交、自动创建额度或自动恢复暂停的队列。

遇到风险、额度或来源状态暂停后，先核对来源状态和额度，再重新粘贴原分享内容并明确选择“继续未完成项”。已成功或重复的博主不会重新订阅。若有已派发但结果未确认的项目，暂不允许继续派发。取消后仍在等待当前项回执时，也不能开始新批次。

关闭弹窗只停止查看，不等于取消队列；“取消批次”才是显式取消。重新打开可读取本地回执。页面仅在当前会话保存不含来源内容的批次编号和待核对提交编号；原始分享文案、临时链接及 token 不写入本地存储，也不进入 tRPC 日志。提交回执不确定时复用同一编号核对，不自动重新派发。

接口位于受保护的 `xiaohongshu` 命名空间：`startSubscriptionBatch`、`subscriptionBatch`、`resumeSubscriptionBatch`、`cancelSubscriptionBatch`。服务端负责真实队列、事务去重、风控和来源预算；离线合成测试不代表真实来源订阅已验收。
