# 小红书原文入口与已存数据

本轮按用户最新要求删除 WeWe RSS 内的小红书正文阅读。标题与公众号列表一致：新标签打开原平台链接，不受正文或视频是否已缓存影响。正文与图片在下载到 Obsidian 后本地阅读。

标题链接只从已保存的规范身份 `["xiaohongshu","note","<id>"]` 生成 `https://www.xiaohongshu.com/explore/<id>`，沿用服务器下载附页的身份规则；不携带或猜测 xsec_token，不接受 javascript、自定义协议、任意域名、非规范 JSON 或含路径/查询的 ID。无有效身份时显示“原文链接不可用”，互动数据仍可查看。打开标题不发起采集。

所有目录记录默认保留。目录数与完整归档数分开显示，归档状态只说明下载准备情况，不再用“能否在平台内阅读”筛掉目录。列表互动快照区分数值 0 和未知。

每条笔记的“互动与评论”独立查询既有 `engagement` 接口，严格传递当前 creatorId、noteId 与本地评论分页。它不依赖正文 API、body 成功、缓存状态或新下载路径。仅有正文、仅有互动、两者都有、两者都无时均保留各自真实状态。面板仅展示已存数据，显式采集操作维持原能力开关与授权语义。

粉丝、互动数、采集时间、评论正文、根评论、回复对象与覆盖窗口均来自本地已存值。未知关注数省略，真实 0 仍显示。不推断平台评论总数等于本地已存条数；顶层返回结束不代表楼中回复完整；回复对象未知保持未知。评论文本按文字渲染。

数据面板正文最大宽度 720px，标题自然换行，关闭按钮留在固定头部，内部只有一个主要滚动区。关闭或切换笔记会卸载旧面板；查询不保留上一笔记结果；显式操作用同步锁防重复，卸载后不写回错误或触发页面刷新。

删除范围：小红书页面原 ArticleReader 入口、正文查询/正文弹窗、readerFind 状态、noteReaderHtml 专用拼装函数，以及互动组件三处旧正文接口 invalidate。保留公众号共享阅读组件、下载/导出/归档/媒体及互动评论模型。后端阅读专用 API 和 sites 脚本由整合负责人移除；本补丁不修改后端。

## 独立离线验证

使用完整安全依赖工作区构建 web 后运行：

```text
node --test scripts/xhs-subscription-ui.test.cjs scripts/xhs-task-recovery-ui.test.cjs scripts/xhs-whole-creator-ui.test.cjs scripts/xhs-note-links.test.cjs scripts/xhs-engagement-visibility.test.cjs
node scripts/xhs-note-data-browser.test.cjs
```

浏览器脚本只启动一个合成 HTTP fixture 与临时 Chromium profile，不启动后端、不复制数据库、不读取凭证；禁用外部域名解析，断言零 POST、零旧正文 API 调用。覆盖 266 条目录的原文链接、320/390/768/1024/1440/1580 宽度、19 评论、长标题、四种正文/互动组合、延迟返回后的关闭与切换。截图仅为合成页面，不能作为真实平台采集成功证明。

视觉验收使用合成页面及临时浏览器环境。合成截图只支持界面与交互结论，不代替真实平台数据、用户环境或生产部署验收。
