# 小红书原文入口与已存数据

WeWe RSS 内的公众号和小红书正文阅读器均已删除。标题用于打开原平台链接，不受正文或视频是否已缓存影响；小红书原文按下述显式准备流程打开。正文与图片在下载到 Obsidian 后本地阅读。

标题采用两步操作：点击“准备原文”显式调用 `xiaohongshu.prepareOriginalLink({noteId})`；服务端返回 ready 后，再点击“打开原文”以安全新标签打开。无预取、自动重试、后台来源请求或裸 ID 回退。浏览器只接受与已存规范身份完全一致的官方 HTTPS 笔记地址，保留服务端验证后的查询参数，不猜造 token/source。临时 URL 仅在当前行状态中使用，不写列表 DTO、localStorage 或日志；关闭页面、切换行身份后丢弃迟到响应。`not_ready` 与失败有固定可见提示，缺额度可直接展开现有来源设置。

识别作者和所有博主的原文共用一份来源请求总额度，服务端同时保留用途／博主范围约束。现有“来源与本机保存设置”和订阅弹窗显示同一共享额度的剩余、已用、总额与间隔；打开订阅弹窗时隐藏背后设置中的重复额度。用户不填写 budgetId，也不为每篇或每位博主新建额度。只有“保存请求额度”显式调用配置接口，保存总额不清零已用次数、不追加额度，不自动发起来源请求。再次打开设置会重新读取额度。已有可用上下文由服务端零请求复用，冷恢复仍受预算、间隔与风险闸限制。固定错误码转为简短中文提示，原始来源错误和 URL 不透传。此 UI 合同不代表真实平台链接已打开成功，整合负责人须独立验收后端。

所有目录记录默认保留。目录数与完整归档数分开显示，归档状态只说明下载准备情况，不再用“能否在平台内阅读”筛掉目录。桌面列表将标题、时间、点赞、收藏、分享、评论、归档状态和操作对齐成列；未知显示短横并标注“未采集”，0 保持真实数值。可用宽度小于 1000px 时转卡片，指标保留字段名。筛选折叠为紧凑工具栏，最近任务每次进入默认收起，自动发现历史任务不展开正文进度。

当前列表展示已存点赞、收藏、分享及评论总数，字段按作者和笔记身份绑定；暂停评论正文及回复的采集和展示，历史记录保留。

粉丝、互动数和采集时间来自本地已存值；未知关注数省略，真实 0 仍显示。评论总数为来源指标，不等同于本地历史评论条数；字段缺失或非精确值保持未知。

列表的指标筛选和排序以整个当前筛选集合为范围，再分页展示；未知值不当作 0。布局及真实使用以合并后的前端验收为准。

删除范围：公众号和小红书的正文阅读入口、ArticleReader 组件、正文弹窗、阅读专用状态与查询，以及小红书阅读专用后端 API、Sites 阅读分支和互动组件三处旧正文接口 invalidate 均已移除。保留下载、导出、归档、缓存、正文生成、媒体及互动评论接口；共享 article.byId 仍供受保护的 Sites 下载路径读取缓存投影，不能作为阅读专用 API 误删。不删除既有数据库记录或已下载文件。

## 独立离线验证

使用完整安全依赖工作区构建 web 后运行：

```text
node --test scripts/xhs-subscription-ui.test.cjs scripts/xhs-task-recovery-ui.test.cjs scripts/xhs-whole-creator-ui.test.cjs scripts/xhs-note-links.test.cjs scripts/xhs-engagement-visibility.test.cjs scripts/xhs-original-link-ui.test.cjs scripts/xhs-source-budget-ui.test.cjs
node scripts/xhs-note-data-browser.test.cjs
```

浏览器脚本只启动一个合成 HTTP fixture 与临时 Chromium profile，不启动后端、不复制数据库、不读取凭证；禁用外部域名解析，拒绝非明确允许的 POST，断言零旧正文 API 调用。覆盖 266 条目录的显式原文入口、320/390/768/1024/1440/1580/2048 宽度、侧栏压窄、列对齐与行高、19 评论、长标题、四种正文/互动组合、延迟返回后的关闭与切换，以及额度仅由显式保存产生。设置 `XHS_DATA_TEST_RECOVERY=1` 另测历史任务每次进入与刷新均收起。截图仅为合成页面，不能作为真实平台采集成功证明。
点击“链接失效？重新准备”会显式发送 `refreshContext:true`，清除该笔记的短期链接缓存并沿现有预算重新获取上下文；不重置账本、不解除来源停止状态，也不自动重试。
