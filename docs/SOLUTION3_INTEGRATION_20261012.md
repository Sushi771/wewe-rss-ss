## 安全部署及回退

迁移前重新核验现有健康、进程完整身份、数据字段基线和安全全备。新增 `cache_insert_batches` 迁移先在副本完成，迁移后启动守卫必须重新取得新 schema 快照。固定产物只通过现有受控入口启动，端口或身份权限失败如实停止，不更改权限或结束其他占用者。
