# 图片来源缺失的导出状态

缓存正文中的图片标签可能没有 `src` 或 `data-src`，也可能在安全清洗时丢失非法来源。删除这种标签并不代表媒体已完整保存。

共享 Markdown 导出器会把此类正文标为媒体完整性未确认，保留可用正文与有效图片并给出提示。列表单篇保存返回不完整，批量 ZIP 将该篇计入不完整列表；原来的 `available` 或 `unavailable` 历史不能掩盖缺失来源。坏图片字节、缺正文和图片数量/大小限制仍受原有校验约束，用户编辑的笔记继续受保护。

批量结果中的不完整项统一使用相对导出文件路径，缺正文和部分媒体的实际文件都可定位。安全导入删除越界图片来源后，该篇仍应保留有效图片并显示完整性提示，不能再按完整篇计数。

这个修复独立于正文重试状态修复。隔离实际单篇与批量入口覆盖了无来源标签、清洗后来源缺失、媒体待核以及坏图片字节；不会自动请求原文或推测线上某篇存在同样问题。发布前需核对对应提交的完整 CI 与独立部署授权。
