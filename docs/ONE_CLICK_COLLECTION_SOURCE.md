# 一键更新的文章来源决策（2026-09-28）

## 2026-09-28 最新执行范围

用户要求彻底移除电脑微信逐号、逐篇采集的产品入口和主动调用，恢复订阅后一次点击更新全部的后台下载流程。本项目测试全部订阅号的执行与本地写入；用户自行在微信核对更新成功与内容，苏洵仅抽查 5 篇。下文关于妈妈 20/20 与苏洵 5 篇的严格逐篇对照是旧阶段的来源验证计划，不能再阻塞工程接入或替代用户指定的批量测试。后台来源仍需真实可用，不能靠 API 文档或 mock 声称生产可更新。当前无 Mp2RSS Feed Key，也未购买服务。

## 用户要求与当前事实

用户要保留原有操作：订阅公众号后，点击一次“更新”或“更新全部”，服务端自行逐号获取最新文章；定时任务使用相同来源。苏洵只抽查 5 篇，产品仍以每号最新 20 篇唯一文章为目标。用户不应在每次更新前手工打开电脑微信、搜索公众号或切换文章页。

旧版按钮调用微信读书文章接口。2026-09-27 的真实官方阅读器首屏返回业务码 `-2041`，公众号后台列表实测返回 `200013`；现存本机会话没有可验收的 20 篇后台来源。当前未绑定新通道的账号会退回封面预览，苏洵普通更新只得到 1 篇，不能称为完整更新。妈妈号已绑定电脑微信通道，生产导入最近 20 篇，重复普通更新新增 0。电脑微信当前还要求目标号的文章页被选中，多号自动切换和定时均未验收。

2026-09-28 新增只读迁移证据：生产 12 个已有订阅号各取最近一条旧文章 ID，构成 `https://mp.weixin.qq.com/s/<22 位 ID>`，逐条请求微信官方页面。12/12 HTTP 200、存在原文正文结构，页面内公众号名称与对应订阅号精确匹配。原始 URL 与逐号结果仅在 Git 忽略的 `output/playwright/provider-source-probe/official-seeds-20260928.json`，不提交文章和个人数据。这证明可为候选服务提供 12 个合法订阅种子，**不证明候选服务已收录最新 20 篇**。

## 候选后台来源与验收门槛

优先试 [Mp2RSS Open API](https://areyoubugcoder.github.io/Mp2RSS/api/)：其文档提供按文章 URL 订阅、查询已订阅公众号及分页文章列表，返回原文 URL、标题、时间和正文 Markdown，服务端可直接调用，不需要每次操作电脑微信。当前公开[计费说明](https://areyoubugcoder.github.io/Mp2RSS/guide/membership.html)为最低 50 个订阅 49 元/30 天；免费试用是否提供以注册后页面为准。服务自述平均 2–3 小时收录延迟，因此它可能满足一键拉取已收录内容，却不能预先承诺“刚发文立刻更新”。本项目当前没有该服务的 Feed Key、会员或目标号 API 响应，尚未购买、登录或向其发送种子链接。

备选 [Wechat2RSS 私有部署](https://wechat2rss.xlab.app/deploy/)公开标价 15 元/月或 150 元/年，文档支持任意公众号、后台更新与 API，但需要自有微信账号和付费软件部署；它不能凭定价推断本机账号可通过风控。既有公开免费目录不含两个目标号。该候选的[API](https://wechat2rss.xlab.app/deploy/api)要求先订阅并以其公众号 ID 查询，仍须实测目标覆盖。

接受任何后台来源之前，先用妈妈号已核验的最新 20 篇做 20/20 对照，再对苏洵抽查 5 篇，核对账号、原文身份、发布时间、正文/图片及次条；检查另一批次重复更新新增 0、失败无文章写入。达标后才接入现有“更新/更新全部/定时”入口，并保留全部旧 ID、正文、图片和有效指标。不要用 200 状态码、套餐说明或旧 RSS 20 条代替覆盖证据。

已新增只读 [Mp2RSS 探针](../scripts/collection-source-probe/mp2rss.py)：在目标号已经加入本人 Mp2RSS 账户、Feed Key 仅存在本机 `MP2RSS_FEED_KEY` 环境变量时，查询精确号名及各号最近 20 篇，检查来源 URL、唯一性、排序、账号 ID，再与本机已核验的妈妈 20 篇、苏洵 5 篇标题对照。它不修改 Mp2RSS 订阅，也不读写 WeWe-RSS 数据库；结果只输出数量和匹配数，不打印 Feed Key 或文章 URL。标题对照是第一道覆盖门槛，仍须后续逐篇官方原文身份验证。

```powershell
python scripts/collection-source-probe/mp2rss.py --reference-dir output/playwright/wechat-desktop-collector
```

当前阻塞在候选服务的真实访问条件：本机无 Mp2RSS Feed Key，免费试用未证实；无目标服务响应，不能把后台接入称作已经完成。用户已允许考虑付费，但实际购买应在服务返回目标覆盖证据或明确接受试用缺失及费用后进行。生产服务仍为旧版来源，定时采集关闭。
