## 非生产验收

优先复用已有校验通过的快照，核对其 SHA256 后建立一个私有验收数据库；单次生成一个备份结果。输入与输出使用正式部署相同的磁盘类型和路径关系，但与正式数据库、正式备份及用户导出目录隔离。数据库、原始记录、环境路径和运行审计不提交 Git。

验收使用实际 Python 备份和实际 Prisma 客户端：在开始复制后提交 ORM、原始 SQL、批量事务和短超时交互事务，验证事务回调进入引擎前等待、只执行一次，备份保留写入之前的合成状态。比较验收前后原有记录的指纹，核对完整性、阶段耗时和复制预算。大库只跑一次；预算耗尽、异常释放、队列过期和退出未确认等故障边界由小型隔离回归覆盖，避免生成成批大库备份。

## 发布范围和边界

发布仍需单独确认并受控重启后端。重启前后执行已验证的备份、启动身份与数据保留检查；不补跑定时任务，也不为验收增加平台访问。发布后观察正常授权操作的备份及写入记录。

固定快照复制预算最多十五秒；应用写入在事务开始前等待，队列等待最多七十五秒、最多二百五十六项。超时或溢出明确失败且不稍后执行。退出未确认的备份子进程会继续阻止新的应用写入，直到实际关闭。协调器只覆盖单应用进程，外部维护脚本、迁移或其他进程的写入须另行安排；队列不提供重启后任务持久化。大库验收证明当前硬件上的一次运行，不保证任何磁盘负载下都能完成。
