# 账号布局验收（2026-10-04）

## 2026-10-05：连接弹窗遮挡及不可连接状态

用户新的桌面截图反馈标题被账号顶栏遮挡、列表展示不全，蓝色禁用按钮的可操作状态也不清楚。此前宽度验收未覆盖这一高度、缩放与点击命中问题，不能沿用为本轮通过证据。

源码确认账号顶栏为 `z-index:100`，已安装 NextUI 的默认弹窗 wrapper/backdrop 为 `z-50`。本轮为连接弹窗使用独立 slot 样式：遮罩和容器分别高于顶栏；容器跟随动态可视区高度；弹窗高度限制为可视区减去两侧留白；只有正文区滚动，标题、关闭按钮和底部“返回账号管理”不进入正文滚动区。复用 NextUI 原有焦点管理、关闭行为和内部滚动，不新增窗口控制工具。

后端 `ready` 仍决定能否连接。不可连接项使用灰色“暂不可连接”，按返回的原因展示“未配置来源”“其他更新通道”或“会话暂不可用”，并保留后端完整说明供阅读及辅助技术关联。事件处理同时拒绝 `ready=false` 和已在提交中的点击；后端账号、登录、旧停止和配置门禁未修改。“返回账号管理”只关闭弹窗，正常登录和平台验证仍由本人通过已有入口处理。

所有候选禁用时，正文滚动区仍需能用键盘到达，因此明确设置区域名称和 `tabIndex=0`，并显示内部焦点边框；不依赖浏览器自动将滚动容器加入 Tab 顺序。焦点进入正文后，方向键/PageDown 的实际滚动效果仍属主线程真实验收项。

纯代码回归 `node --test scripts/check-account-modal-logic.test.cjs` 覆盖真实确认事件处理函数的禁用、提交中、取消及准确提交路径，返回按钮只关闭弹窗，以及已命名键盘目标、遮罩层级关系、动态高度留白、正文收缩和内部滚动的样式合同。测试只读源码并使用内存回调，不启动应用、浏览器或网络；高度计算包括 956px/200% 和 480px/200% 情况。它不能证明实际像素、点击命中、焦点移动或滚动效果。

本轮须在集成后的实际页面完成以下检查；源码、构建和 CI 不能代替这些结果：

- 桌面可视区 2048×956，缩放 100%、125%、150%、200%；记录实际 `innerWidth/innerHeight`，标题、关闭按钮、底部返回按钮均在可视区内且不被固定顶栏覆盖。
- 窄屏 390×844、320×568，以及低高度 1024×480；12 个候选、长名称和多行拒绝原因仅在正文区滚动，首项和末项都能到达。
- Tab/Shift+Tab 保持在弹窗内，Escape/返回按钮关闭并恢复合理焦点；不点击平台登录、刷新或生产连接确认。
- 实际点击命中标题、关闭按钮和返回按钮均属于弹窗；无顶栏或底层页面抢占。
- 隔离离线候选中验证可连接按钮可点击、禁用项确实禁用且原因可见；实际账号若因平台拒绝、失败凭据或未配置而禁用，不能据此解除门禁。

此工作窗口未提供 Computer Use 必须使用的 `node_repl`，未用自制自动化绕过该要求，因此本轮真实视觉、键盘、缩放和点击命中仍待主线程验收。新 Library 参考图的当前 Windows 正式读取流程也未完成；没有宣称在本窗口查看该图。

## 2026-10-04 历史验收

`ffcc668` 已实现隐藏前端账号编号、保留经身份校验的微信读书昵称、自适应行高、最近扫码标签、横排状态选择器及小屏操作换行。真实本机部署页面在 1970、1280、1001、1000、900、641、640、390、320 像素宽度下通过这些检查；未点击登录、连接确认或刷新，未请求腾讯接口。

桌面表头及账号行的操作列原先各自按内容计算宽度，表头和失效账号行因此与正常账号行错位。此次将账号栅格的桌面操作列统一为 240px，沿用已有窄屏布局；连接弹窗使用现有组件的内部滚动模式，避免 12 个选项在手机端将标题和前几个订阅挤出屏幕。后台账号身份校验、绑定选择、正文与保存模块保持原实现。

复核要点：

- 正常、失效、长昵称账号的表头和四列起点一致；各行内容不能越界或与相邻行重叠。
- “启用”不竖排断字，最近扫码标签跟随实际最新的扫码时间，而非固定跟随某个昵称。
- 前端列表、连接预览及确认文案不展示账号编号；后台仍使用稳定账号 ID。
- 小屏能展示昵称、时间与全部操作，页面无横向溢出。
- 连接弹窗按后端返回的选项逐项展示名称与原因，不预选、自动连接或自动刷新；12 个选项时标题、关闭按钮及首个订阅可见，最后一个订阅可以滚动到达。

初次布局包仅返回已配置来源且属于手动更新通道的订阅，并未写死公众号名称。最终整合后，实际组合包九种宽度及列对齐通过，手机弹窗真实列出12个订阅，11个未配置原因可见、最后一项可滚动到达；最新扫码标记跟随实际最新账号，未固定昵称。平台当前停止保留，未点击确认或发刷新。全部订阅真实取文覆盖仍待验收；布局通过不代表目录、最新十篇正文或图片更新成功。
