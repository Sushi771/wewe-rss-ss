# 下载入口页签验收

基线：ff150609305ae21ecaaac8cf41deb8e3f0e025ab。范围：下载工具页及其路由引用。统一公众号与小红书下载入口，使用现有 NextUI Tabs、Card、Input、Button，主体最大宽度 42rem。窄屏卡片和输入自然收缩，下载按钮占满可用宽度，保存目录操作换行。

## 产品行为

- /dash/tools 默认公众号；既有 /dash/tools/article-download 与 /dash/tools/xiaohongshu-download 深链接继续可用。
- 同时只显示一个平台表单。NextUI destroyInactiveTabPanel=false 保留两平台组件挂载；非当前面板隐藏且 inert，页签具有组件原有的键盘与可访问关系。
- 切换不清空链接、结果、错误或后台任务，不停止请求/轮询，也不触发重复下载或浏览器任务取消。离开整个工具区域仍执行原有组件清理规则。
- 保存路径、下载确认、目录令牌、持续任务、暂停/恢复、缓存文章精确选择和平台能力判断沿用原处理。两个原表单 return 之前仅 toast 文案加平台名称，其余处理代码与基线逐字一致；后台错误通知即使切换页签也能识别所属平台。
- 平台状态分别在对应面板显示。没有接通的小红书显示“暂不可下载”，提交按钮禁用；本次未新增小红书取文能力。

## 技术与浏览器验收

## 集成与限制

App.tsx 仅替换旧工具导航包装及三处 tools 路由元素为 DownloadTools；不改 feeds、日历或后端调度。DownloadTools 内调用两个既有表单，无平台 API 或协议变更。父任务按统一基线集成、发布后再核对真实页面。

默认 CUA 初始化失败；本次可用的是独立临时 Edge/Chromium 浏览器，不声称默认桌面验收完成。真实小红书下载、腾讯正文、登录、目录原生选择器和磁盘写入未执行；mock 成功不能证明任何真实上游已恢复。任务清理、暂停恢复及精确选择处理未改，其业务正确性仍依赖原有测试和后续统一验收。
