# 前端开发原则

用户于 2026-10-10 明确要求：组件不要过度开发；GitHub 有现成库就优先复用，以后开发也遵循这一原则。

优先使用项目已有的 NextUI 和 sonner；只有现有组件无法满足具体需求时，才评估维护状态、许可证、依赖成本后引入成熟开源库。库已有的 portal、焦点管理、键盘交互和通知能力直接复用，不重复实现通用框架，不为简单界面新增大型依赖。

订阅添加界面只显示后台真实状态对应的进度和完成数量。等待缓存不伪造百分比，失败、取消和跳过不计为成功；正常完成短暂反馈后收起。后台保留任务历史，前端不常驻历史入口。新异常聚合提示、按任务状态转换去重，关闭提示不取消任务；仅保留有实际后端能力支持的继续操作。

验收区分离线组件测试、浏览器隔离布局测试与真实产品交互。没有真实点击、键盘和焦点验证时，不把测试替身称为实机验收。
