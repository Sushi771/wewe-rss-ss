# 小红书正式入口与采购前接线

正式入口是 `/dash/xiaohongshu`，导航显示“小红书”。页面使用登录保护下的 `trpc.xiaohongshu`，不引用交互原型的虚构博主或笔记。

## 已接线的工程能力

- 保存公开主页和备注到待接入名单、暂停/启用、移除无归档的博主。保存结果始终 `subscribed:false`，不代表供应商订阅、作者身份确认或已读取内容。主页不解析成可信作者 ID，不读取登录参数、不解析短链、不请求平台。
- 正式博主列表、笔记列表、纯文本和按序缓存图片查看；单博主/已启用博主批次更新状态。缓存完整图文以本机直存为主入口，ZIP 为可选导出。未配置来源时更新禁用，服务端返回 `unconfigured`；无已核完整图文时下载拒绝。已有归档的博主只能暂停，移除不会删除历史。处理期间禁用博主选择，更新回执标明对应博主。
- 桌面添加表单的输入框分担剩余宽度，保存按钮保留完整文字所需宽度；窄屏保持纵向布局。修复依据是隔离浏览器观察到的桌面按钮裁切，实际修复后视觉结果须另行核验。
- 服务注册在原 `TrpcModule`，新增命名空间复用原登录中间件。可选内部 `XHS_SOURCE` 默认**未注册**，无环境变量开关或假供应商 adapter。正式界面不会出现测试内容。

内部来源交付本项目正规化的作者身份、分页及 `XhsNormalizedCandidate`，还须由服务端 adapter 先确认真实身份和全篇/媒体证据。`evidenceVerified` 仅来自内部服务，不允许浏览器上传。候选合同的 `verified:false` 不因结构通过而自行升级。采购前仅在临时数据库中注入合成来源。

内部接线复用现有合同，核对作者归属、整数秒发表时间、正文完整状态、图片数量/顺序与实际字节；视频单独标为未归档。失败停止，旧内容不变，不自动重试或切换来源。最多处理三页的有限窗口，非终止游标返回 `partial`，不宣称全历史；批次遇失败或未完成窗口停止。重复笔记保留旧完整正文和图片，新增为零。刷新、暂停、移除共享单博主进行中锁，不提供跨重启任务保证。

## 两张追加表及旧数据保护

迁移 `20261009050000_add_xhs_local_archive` 仅追加 `xhs_creators`、`xhs_notes` 和索引/外键。`Account/Feed/Article` 表结构、原 ID、正文、指标、微信归档与下载路由均不改。

原单篇离线图片导入脚本兼容迁移前的四表结构与追加小红书两表后的六表结构；备份、演练和写入前后的快照仍逐表全量比对，包括已有小红书缓存。未知表、只存在一张新增表或演练后缓存变化均停止，不跳过新增表的旧数据保护。

博主本地主键与上游作者 ID 分离，待接入记录的上游 ID 为 null。笔记用已有平台/笔记 ID 元组编码和独立博主外键。完整图文缓存转义文本段落和经过字节检查的 data URI；视频无正文缓存。不新增媒体、任务、授权表或来源管理框架。

业务写入沿用一致性 SQLite 备份门禁。正式迁移须先备份，在副本应用并逐字段核对旧表，再按现有迁移部署流程执行。本轮仅在临时 SQLite 演练，未迁移生产。构建使用现有依赖：`pnpm --filter server exec prisma generate` 后构建；不得把新代码直接启动在未迁移的旧库。回退前保留新增表与文件，不用破坏性回滚删除归档。

## 原归档器复用

“保存缓存图文到本机”复用原 `LocalArticleStore` 和 `buildCompleteArticleDownload`，沿用文章下载工具的目录设置。按北京时间的下载日期建目录，每篇是 `正文.md` 与 `image/`，图片为相对路径，无需解压。保留原本机访问、登录、Origin、进行中锁、原生目录选择及一次选择凭证；不覆盖已有保存和用户手写笔记。请求仅包含博主/笔记 ID 和原目录选择凭证，不接受路径、HTML 或图片 URL。逐篇串行保存，取消目录选择或失败立即停止，已成功保存的篇目保留。只在桌面本地访问可用，不提供云端服务器向用户电脑写文件。

页面图片是 SQLite 缓存中经过检查的实际图片字节（data URI），不是远端 URL。直存先核正文和每张缓存图片，再由原 Markdown 导出器落盘，禁止网络回退。当前仍须接入真实供应商后验证真实媒体，合成缓存测试不代表已取得平台原图。

“导出 ZIP（可选）”保留原 `buildArticleMarkdown` 和 `archiveDirectory`，Markdown 图片为相对 `attachments/`，ZIP 可断网打开。单次缓存 HTML 总量上限 25MB，超限拒绝，不截断。两种保存均不把小红书 ID 传入微信下载入口、不扩大微信 CDN allowlist。云端归档及私人 Sites 未接入。

## 离线与真实验证边界

离线验证使用实际受保护 router、服务、Prisma SQLite、原备份、正文/图片导出和 ZIP 字节；本机直存通过实际 HTTP 控制器核对日期目录、正文、相对图片路径及图片字节、重复保存保护、权限和取消目录选择。迁移前后旧账号、公众号、文章逐字段全等，检查数据库完整性和外键。UI 验证真实 handler、路由及生产构建，尚未做浏览器视觉验收。归档子进程用于处理 Jest CJS 对已有 archiver ESM 的加载限制，执行原归档源码，不伪造 ZIP 成功。

仍需采购后核实 A/B 文档实样、认证计费、作者/笔记身份、时间分页映射、完整正文/全图、签名域名与字节下载，以及 B 的私人归档许可和运行依赖。真实首轮仅一个确认博主前三篇，重复更新新增零，副本归档断网开文图；遇认证或限制停止。尚未发真实平台请求、启用来源或部署生产。
