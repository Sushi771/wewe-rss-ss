# 界面提示与导出说明

正常界面先说明当前状态和下一步。接口返回、来源检查、文件处理规则放在可展开的详情中。登录失效、权限不足、存储不足、官方验证、频率限制、部分图片或视频不完整、操作结果未确认仍直接提示，不能以简化文案代替真实失败。

操作结果未确认时，通用错误标题只提示检查状态和详情，不默认引导重试。恢复任务的按钮标为“继续处理”：它会恢复原任务的处理或检查，并非只读查看进度；原有停止、恢复条件及后台调度逻辑保持不变。

导出文章保留范围选项及其数量、导出方式和开始按钮。“选中文章”仅包含手动勾选的文章；“当前筛选”包含所有匹配结果；“全部”忽略当前筛选。每次保存到 Obsidian 最多 5000 篇，保留已有文件并检查是否需要补齐。ZIP 仅支持单个公众号的当前筛选或全部文章。更多范围及文件规则见“范围与文件说明”。实际完成数量可能随文章变化，与开始前数量不同。

搜索默认显示是否仍有正文未纳入结果，以及未保存正文无法搜索的事实。“查看搜索范围”提供全局数量和匹配方式；准备过程可暂停、继续，不改变联网取文权限。
