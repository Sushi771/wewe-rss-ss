## 当前产品边界（2026-09-27 本轮修订）

目标是由 WeWe-RSS 内置授权、列表分页、正文获取和入库；外部下载器、MCP 包装、读取下载目录均不能成为订阅依赖。目前**完整公众号列表通道仍未验收**。已验证的公开合集只覆盖绑定范围，不能覆盖“全部”页中的所有内容。

普通更新、历史入口和定时任务不再读取外部目录。已存在的目录记录仅保留供显式文件迁移使用；导入不切换在线来源、不覆盖合集绑定、不启用定时任务。创建的文件导入公众号默认关闭定时更新。采集结果区分 `partial`、`blocked`、`failed`，并保存在公众号记录中，刷新页面后仍可查看最近一次订阅操作结果。

用户截图来自**手机微信**。近期“思维100”、物理竞赛、四校八大与化学内容尚未取得原始列表身份，类型、目标号发布时间及次条范围待验证；不能按普通文章猜测。

## 免费在线公开合集补采（2026-09-27 实测）

公众号页面新增“公开合集补采”。输入该公众号的公开合集 ID，点击采集并绑定；此后原有“更新”、历史补采和定时任务直接在线读取绑定合集，不需要先制作 CSV，也无需公众号后台账号或微信临时凭据。

目标“妈妈部落畅聊阁”已验证的合集 ID：`2527940920407949313`（徐汇区）、`3588220544052641807`（复旦数学营）。公开列表分别为 13、19 篇，每页 10 篇，合计 4 页、32 篇唯一文章。实测记录见 [REAL_COLLECTION_ACCEPTANCE.md](./REAL_COLLECTION_ACCEPTANCE.md)。

**这条通道只覆盖所选合集，不是完整公众号历史。** 未归入所选合集的文章无法通过这次采集发现；真实列表全部为 `idx=1`，次条完整性尚未验证。界面保持“采集范围受限”。合集总体阅读量不会写成文章阅读量，文章阅读、点赞、收藏仍显示未获取。

- 合集页链接包含 `album_id=...`。可输入 1–10 个同一公众号的合集 ID，用逗号分隔。
- 按末条的 `msgid` **和** `itemidx` 翻页，直到 `continue_flag=0`。校验首屏总数、重复游标和公众号身份；任何一页失败时本次不写入，保留原有绑定和文章。
- 以 `biz + mid + idx` 去重。对于同标题旧短链候选，读取原文核验身份后才合并，保留旧 ID 和真实发布时间；核验受阻会中止，避免制造重复。合集时间与原文时间可差几十秒，不能用模糊标题时间合并。
- 绑定公开合集后更新仅补采这些合集。显式文件导入不会改变该绑定；不会删除其他存量文章，已有正文和指标保留。
- 每个合集最多 50 页，页面间间隔 350 ms。上游可能返回验证页或网络失败，不能保证一直可用。
- 如直连受限，可在不提交 Git 的 `apps/server/.env.local` 配置 `WECHAT_PUBLIC_PROXY_URL=http://127.0.0.1:7890` 并重启。本次仅复用了用户已有本机代理，没有更改 Windows 全局代理。只支持无凭据的回环 HTTP 代理；不配置时直连。

## 一次性文件迁移

文件导入仅用于用户已经持有的 CSV/HTML 数据，不是订阅修复方案，不要求安装任何下载器。

1. 进入公众号页面（新号进入“全部”），点击“导入已有文件”。
2. 输入 CSV/HTML 所在的绝对目录路径，支持下三级子目录；新号填写名称。
3. 点击“预览”，核对公众号、文章数、匹配正文数，再点击“导入一次”。
4. 导入不会绑定目录、改变现有在线来源或开启定时读取。后续有旧文件要迁移时，需再次明确执行导入。

## 正文与去重

- CSV 必需列：`title,url,time`；同时支持 `标题/文章标题`、`链接/文章链接`、`发布时间/日期`。链接须含 `__biz`、`mid`、`idx`。短链 CSV 不能提供稳定的公众号与次条身份，当前会提示错误。
- 以公众号标识、`mid`、`idx` 识别文章，去除链接内凭据与跟踪参数。主条和次条独立保存，重复导入不重复创建。
- 对同标题的旧短链候选，在写入前读取原文并核验 `biz/mid/idx` 身份；标题和时间都不是合并依据。身份一致才保留旧 ID，原文核验失败或多条旧记录指向同一身份时整次不写库。已核验同一身份的长短链重复合并时保留旧 ID、正文和已有指标；可信原文日期优先，重复导入不以 CSV 的秒级偏差覆盖已有日期。此项核验可能需要网络，预览仍只读本地文件，不能替代导入身份核验。
- HTML 通过 `og:url` 或 canonical 链接匹配 CSV。正文读取 `#js_content` / `.rich_media_content`，删除脚本与事件属性。找不到正文会提示；只有 CSV 的文章仍可分析热度，但在线正文导出可能失败。
- 本地 PNG/JPEG/GIF/WebP 图片随正文存入数据库，不依赖原采集目录继续存在；只读取采集目录内的图片，远程图片尚未本地化时仍需网络。视频、音频、MHTML 和仅 Markdown 的导入暂不支持。
- 上限：扫描 10000 个目录项，5000 篇/次；单 CSV/HTML 10 MB，单图片 5 MB，单篇正文及图片 20 MB，总内容 200 MB。超限按日期分批采集导入。不要选择整块硬盘根目录。
- Obsidian 导出位于配置目录的当天日期子目录，图片位于其 `attachments` 子目录。文件名包含文章 ID，防止同名文章覆盖。

## 热度字段

| 含义 | 支持的 CSV 字段（部分）                      | 缺失时          |
| ---- | -------------------------------------------- | --------------- |
| 阅读 | `read_num` / `read_count` / `阅读量`         | 留空            |
| 点赞 | `like_num` / `like_count` / `点赞数`         | 留空            |
| 分享 | `share_num` / `share_count` / `分享数`       | 留空            |
| 评论 | `comment_count` / `评论数`                   | `{}` 也视为缺失 |
| 在看 | `wow_num` / `在看数`                         | 留空            |
| 收藏 | `favorite_count` / `favorite_num` / `收藏数` | 留空            |

作者公开示例是 `title,url,time,like_num,read_num,share_num,comment_count`。没有证据表明能稳定取得其他公众号文章的收藏总数，程序不会用分享或在看冒充收藏。采集软件是否把取不到的指标输出为 0，本项目无法判定；CSV 中真实写入的 0 会原样保存。

列表可按阅读量/点赞量排序，未提供的项排在数值之后。选中文章后“导出热度”仅导出选中项；未选择时导出当前公众号及搜索范围（最多 10000 篇）。CSV 含原始显示值、数值/下限、各指标的数据文件时间；可在 Excel 筛选分析。

`10万+` 数值排序按下限 100000，原始值仍保留 `10万+`。`fileTime` 来自 CSV 修改时间，是来源文件的时间，不是精确采集时刻。复制或手动修改文件可能改变这个时间。新文件的非空指标更新旧值，旧文件和空值不会抹掉已有较新指标。Markdown 同时附上指标表。

## 启动与维护

`启动WeWe-RSS.bat` 停止旧后端后调用 `scripts/prepare-local.cjs`。源码/依赖/数据库结构有变化时备份 SQLite，生成 Prisma 客户端，构建后端与前端，然后部署迁移。备份在 `apps/server/data/backups/`，该目录不提交 Git；构建失败会停止，修复错误后重启。普通启动无需重复构建，但仍检查数据库迁移。

导入接口只接受本机回环地址连接（`localhost` / `127.0.0.1`），沿用应用鉴权。不要把微信凭据、数据库、个人 CSV/HTML、第三方程序加入 Git。手工数据库回滚应先停止服务，并保留当前数据库副本；不要执行 Prisma reset。
