# 已保存正文图片维护

维护已核实文章时，保留用户正文、笔记和原文来源，只补充同一原始图片地址。来源冲突和无来源占位不按标题、顺序或图数猜配。HTTP 200 也必须通过图片容器校验和完整解码后才能称为图片成功。

## 独立内容核对标准（2026-10-24）

正文从原始材料到库、Markdown分别比较，仅允许转义和空白规范化；不得删标点、重排段落或忽略字符差异。图片逐项对应原始有序清单、保存字节和Markdown引用，以独立解码及内容哈希验证；同图数、可打开或保存器成功回执单独均不足以证明原图与顺序正确。

使用合成“正文删段/改标点、图数相同但换图/换序、损坏字节”等反例，检查器不调用被测parser生成唯一期望值。真实对照材料沿已有授权由原负责人保管，本轮不读、不重采、不进行维护写入或删除。新改进仍待 [验收反例](xiaohongshu/ACCEPTANCE.md#深入改进反例与判定)及实现结果；下方历史维护记录不扩展本轮权限。

## 大正文写入

私有批次原先把唯一一次 CAS `updateMany` 放进 Prisma 交互事务。包含多 MB Base64 的正文序列化与提交超过默认 5 秒期限，导致已下载图片未入库。维护入口 `scripts/saved-media-cas.cjs` 改用单条 SQLite 原子 UPDATE，不扩大交互事务超时。传入原始 SQLite 行，精确比较文章 ID、公众号 ID、更新时间、旧正文、两种来源和正文状态；nullable 字段使用 `IS`。并发改动拒绝覆盖，SQLite 语句失败整体回滚，重复的已完成正文不写入。仅更新正文、正文状态和更新时间。

入口是维护用库函数，不是开放 API。调用前必须确认唯一写入者，精确停止所属服务，核验完整一致性备份，并用副本演练。下载和图片解码放在写入之前；恢复服务必须位于 finally 路径。写入后逐表比对，允许目标文章的三个字段变动，保留其余所有文章、笔记、订阅及非目标表。

## 图片预算

日常归档默认仍为每篇 20 MB、单图 10 MB、最多 60 图。显式维护可向 `archiveProviderImages` 传 `maxArticleImageBytes`，必须为正安全整数且最高 30 MB；非法值在任何请求前拒绝。该选项不接入刷新调度或用户配置。本次一篇 53 图已验证合计 23,162,938 字节，显式 30 MB 预算用于完整归档；另一篇 21 图合计 5,476,890 字节。已验证响应持久保存并按规范化原始 URL 哈希索引，重新执行不重复下载。

00:00–06:00 禁止日常主动刷新。本次立即补图是用户明确要求的一次性维护例外，不改变长期时间表，不新增订阅，不重新订阅，不访问小红书，不绕过限制响应。

## 验证

Node 24：`node --test scripts/saved-media-cas.test.cjs`。真实 SQLite 覆盖大正文准备超过 5 秒、七类 CAS 冲突、故障回滚、幂等和非目标数据保护。该测试接入 Windows Node 24 CI。

Server：`pnpm --filter server exec jest --runInBand --runTestsByPath src/collection/archive-provider-images.spec.ts src/collection/image-fetch.spec.ts`。覆盖正常 20 MB 上限、显式 30 MB 维护预算、非法预算、来源精确匹配及限制响应。完整数据、图片原始地址、备份和执行清单仅保留在私有证据中，不提交 Git。

## 2026-10-13 实测交付

两篇事务失败文章已实际补入 74 处内嵌图片引用（69 个不同图片字节），目标分别为 21 图和 53 图，均达到 available。生产单条 CAS 分别耗时 120 ms 和 404 ms。与前一批合计 39 篇、279 处图片引用已补齐。所有本次新增图片通过容器校验及 Pillow verify/load 完整解码。

写前完整备份和真实全库副本演练通过；生产写后逐表摘要相等，目标外全部文章与笔记、订阅及非目标表保留，14 个订阅、1728 篇文章不变，SQLite integrity_check 为 ok。用户原有两处未提交修改未改变，也不纳入提交。

恢复服务时，C 盘不足导致启动审计失败并保护性禁止写入。维护备份已校验后迁至充足空间磁盘，保留原路径目录联接；新启动审计目录也使用该磁盘，不跳过备份或写入门禁。最终服务 ready/writesAllowed 由私有验收记录核实。

准确剩余为 5 个唯一远程地址：一篇来源冲突 3 个地址，一篇两次返回 HTTP 200 但各 432 字节且不可归档的 2 个地址；另有三篇合计 11 个无来源占位。保留原文，不猜配来源，不重放受限请求。这些剩余条件不再被记作事务故障。
