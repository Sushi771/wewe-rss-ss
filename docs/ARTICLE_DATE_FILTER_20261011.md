# 文章日期筛选与时间排序（2026-10-11）

## 使用

订阅文章列表增加“原文发布日期（上海时间）”小筛选栏。使用浏览器原生日期输入，可选单日或起止日期；起止日期可只填写一端。“清除日期”恢复全部日期。发布时间排序可选“最新在前 / 最早在前”，与分组、公众号、标题/公众号关键词组合；原有阅读量、点赞量排序仍保留。

日期使用库内 `publishTime` 原文发布时间，不使用同步、下载或搜索索引时间。未知时间继续显示“发布时间未知”，日期筛选不将它补成当天。存量发布时间可信性仍以原有来源核验为准，本功能不修改文章时间、不迁移数据库或笔记。

筛选变更清空选择并回到首批 20 篇，后续继续服务端游标分页；列表仅返回摘要和正文缓存状态。全选仅包含当前筛选已加载的文章。选区导出只用当前选择 ID；未选文章时“导出当前筛选热度 CSV”使用与列表相同的日期、分组、公众号、关键词条件。反向或无效日期不会提交文章查询和 CSV 导出，并显示简短提示。

筛选沿用应用现有页面内状态，不新增 URL 参数或存储系统；整页刷新恢复全部日期与默认最新在前。切换筛选的查询输入彼此隔离，不显示上一条件的数据；返回旧条件也重新从首批分页开始。

## 查询合同

- `ArticleSchemas.list` 增加 `dateStart/dateEnd`（严格 `YYYY-MM-DD`）、`group`（`all / ungrouped / 分组 ID`）、`direction`（`asc / desc`）。不设置时维持原有发布时间降序、ID 降序行为。
- 日期区间为上海起始日 00:00（含）到结束日次日 00:00（不含）；单日同时设置两端。服务端拒绝无效日期和起止反向。
- `articleListWhere` 供 article list、summary 和 CSV 共用。发布时间排序以稳定 ID 作第二排序字段；指标排序仍降序。分组与公众号为交集，不越过所选分组。
- 切换分组时展示该组全部公众号文章，可继续选择组内公众号；日期筛选不限制产品订阅总量。
