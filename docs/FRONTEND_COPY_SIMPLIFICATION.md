# 前端说明精简（2026-10-10）

## 长期界面原则（用户于 2026-10-18 明确）

普通用户页面不展示供开发者或运维阅读的实现说明、内部字段、回执诊断和容量预测。日常阅读页保留必要操作、进行中的进度、简短真实异常和恢复入口；详细原因放日志、文档或用户主动打开的明确管理详情。不能通过隐瞒真实危险、改写成功状态、把跳过当成功来实现简洁。新功能及回归验收均遵循此原则，不因后端新增 message 就直接常驻拼到阅读页。

本轮只调整公众号阅读页及其现有工具页详情，不做全站重设计。非阻断备份预测从文章列表移入工具页“存储与备份”；真实数据检查阻断仍显示简短提示和详情入口，具体写入失败保留简短错误。沿用 PR55 的按实际定期节奏估算，不把预测或预算限制描述成物理磁盘已满，也不改变写入、备份或删除门禁。

更新进行中保留单条进度；只有应更新、已提交和已完成一致、无跳过/排除/待完成/异常且逐号均成功时才采用紧凑成功状态。页面实际观察到运行转成功时提示五秒，再显示原批次时间；重进页面和重读旧批次不重新弹成功提示。精确计数与逐号记录保留在原详情内，暂停和异常提醒继续可见。移除“筛选与排序在本次浏览中记住”说明，保留记忆、排序和清除操作。

分页底部明确显示加载、失败重试或当前范围全部显示。读取失败保留已加载文章，重试缺失的下一页；仅成功确认没有 cursor 时终止。后端仍以未展示的第 21 条作为下一页起点，不新增 `skip:1`。回归覆盖至少三页、分组和排序切换、窄宽及短屏的实际按钮可见性、失败后重试与原筛选记忆。所有数据库和页面数据均为合成，未读取生产文章或根据未见截图声称复现。

公众号文章列表保留简短篇数、每篇未缓存状态、阅读及重试操作；不再显示存量明细、缓存总数和库内日期范围面板。指标排序所用的 summary 查询保持原合同。

工具页保留链接、保存位置、路径选择、下载设置、必要进度及简短结果。来源与按需订阅说明、长帮助和保存目录教程移至 [文章下载说明](ARTICLE_DOWNLOAD_TOOL.md) 与 [离线目录](OFFLINE_ARTICLE_LAYOUT.md)。用户随后确认的新规则为 `YYYY-MM-DD_分组/公众号/文章标题.md`，公众号目录下保存 `image/`；日期取上海时区真实原文发布日期，无可信日期时使用“日期待核”并提示原因。新导出实现由导出负责人负责；界面精简本身没有改保存器或移动已有文件，也不恢复长目录说明。

用户主动操作失败时复用 Sonner toast 提示一次，页面保留简短错误和恢复按钮；后台任务暂停、失败、取消与媒体完整性未确认仍明确显示，不改成成功或完整。后台详细原因继续沿用已有日志、回执及持久任务记录。状态轮询失败只显示简短重读入口，不新增 toast 轮询、不扩建诊断面板。

单篇下载与旧接收任务的持久化、重载恢复、取消、继续原下载、选择已缓存文章和保存按钮均保持原条件及接口。关闭页面不会取消已受理任务，再次进入继续读取既有任务。本轮不改采集、身份核验、队列、后端接口或发布包。
