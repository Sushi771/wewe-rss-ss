# Redbook 本机确认：使用

本入口只在 Windows 本机提供小量诊断，正式批量归档和审核启用保持关闭。无需设置或记密码；必须在启动窗口明确确认当前浏览器。

先按 [开发说明](REDBOOK_LOCAL_CONFIRMATION_DEVELOPMENT.md)准备与当前源码对应的编译产物。在仓库根目录运行：

```powershell
scripts\redbook-local-confirmation\start-paired-redbook.cmd -ArtifactDirectory "D:\isolated-redbook-artifact"
```

看到“本机确认页面已启动”后，打开 `http://127.0.0.1:49163/pair`，点击“请求本机确认”。确认这是自己打开的页面，将网页六位核对码输入启动窗口。未进行这次本机确认前，没有浏览器访问凭证，不会请求平台。

核对码两分钟有效，三次错误后失效，一次兑换。访问从操作者批准起绝对有效 24 小时，不因使用续期，只绑定该页内存中的浏览器证明。凭证不进入 URL、日志、剪贴板或浏览器存储。

启动窗口输入 R 撤销访问与诊断会话，清理成功后可重新确认；输入 Q 停止实例。清理失败时浏览器访问立即失效，新配对锁住，必须按 R 重试清理或 Q 停止。关闭实例即失效；关闭或刷新网页仅丢失该页凭证，请在启动窗口按 R 或 Q 清理服务端授权。

确认后可保存待核验博主与读取本机状态。平台操作都需在页面手动触发：最多一页列表、一篇选定正文；图片默认关闭，另行确认后至多两张、合计至多 1 MB。失败消耗对应预算，不会自动换签、回退、换端点或重试。仅保存待核验博主不构成订阅或可信作者审核。

真实小红书登录字段只能由用户在本机页面填写，不发送到聊天或提交到 Git。诊断会话仍沿用原实现的本机内存保留上限 24 小时，**这不是经验证的平台 Cookie 有效期**，绝对到期不可通过请求续期；平台提前失效即清除登录信息。去除凭据后的待核验样本可在本次访问中查看，撤销时清空。

服务只绑定 `127.0.0.1`，使用 49163/49164；端口被占用时拒绝启动，不停止其他服务。每次启动生成新的临时合成库与内部保护值，不读取已有 WeWe 密码或生产数据库。凭证与样本不落盘；临时库仅保存用户明确填写的待核验博主备注和主页，停止后可删除相应临时目录。

这里提供的是诊断入口代码，合成验证不能证明真实平台签名、全文或全图已经可用。真实测试必须由用户自行启动、确认并逐步手动执行；遇限制即停止。

Windows 双击入口在 PowerShell 完成撤销和进程清理后停留，保留可读错误代码，按键才关闭；错误提示停留不延长实例或凭证生命周期。浏览器访问与登录信息都受本次批准起 24 小时绝对期限约束，平台自身失效可能更早。
