# 本地标题与缓存正文搜索

本开发分支新增，尚未合并或部署。搜索始终在服务器本地 SQLite 运行，不使用 AI、向量服务或外部正文传输，不自动取回未缓存文章。

## 产品行为

在文章搜索框输入即可查标题、公众号名称和本地已缓存的可见正文。中文单字、双字、长词和标点按字面包含匹配；`%`、`_`、引号和 SQL/FTS 语法均为普通字符。ASCII 英文忽略大小写，其他字符保持原样，不分词、不纠错、不做简繁转换。沿用公众号、分组、上海时区日期、排序和第一条未见游标分页。

正文命中展示前后文和高亮；片段由 React 文本节点与 mark 渲染，不插入 HTML。标题／公众号命中可以没有正文片段。脚本、样式、隐藏内容、HTML 属性及内嵌图片 data URL 不参与正文搜索；实体解码后才提取可见文本。

界面显示全库文章数、未缓存正文数和待整理数，不能把部分结果称为全部正文搜索。输入搜索时自动分批整理本地投影，完成后刷新列表与统计；可以停止、继续，离开或清空搜索后不继续整理。正文仍在来源获取范围之外时，只能搜索标题。整理错误会显示提示，数据保持待整理，下次可以续接。

新插入、正文修改、正文清空和删除由数据库触发器在原事务中同步失效投影；标题与公众号名字直接查询原表，立即可查。正文修改后旧词立刻失效，新词在整理完成后可查；活跃搜索按 5 秒间隔读覆盖状态并续整待处理记录。没有独立常驻后台索引服务。

## 最小方案比较

在当前 Prisma Client 5.10.1 实际 SQLite 3.41.2 引擎的合成库核实：

| 方案                       | 中文短词／标点                                           | 维护与成本                             | 选择       |
| -------------------------- | -------------------------------------------------------- | -------------------------------------- | ---------- |
| 直接搜索原始 HTML          | 会误命中属性、脚本、base64；实体内容也不正确             | 无投影但语义错误，反复读大正文         | 不采用     |
| FTS5 unicode61             | “中文短词”中的“中”“中文”“短词”均不能按子串命中           | 需要中文分词或额外 token 维护          | 不采用     |
| FTS5 trigram               | 三字“中文短”可命中，一／二字不能命中；标点需完整语义处理 | 短词仍需扫描，还增加倒排索引和同步维护 | 本轮不采用 |
| 可见文本投影＋参数化 instr | 支持中文短词与字面标点，无 FTS 操作符                    | 一次整理，单独窄表，长库仍是包含扫描   | 采用       |

未声称这是倒排全文索引。正文投影使用已有 cheerio 依赖，无新增分词包。搜索首屏按原排序索引取有限结果；有游标时使用排序值和 ID 比较，包含第一条未见记录，也保留指标 NULL 的排序语义。统计与列表分开读取，统计仍需要扫描当前筛选范围。

## 一致性、恢复与写入成本

新增迁移 `20261020160000_local_body_search` 只建立派生表、覆盖索引和三类触发器，回填待整理身份与正文存在标志，不在迁移或采集事务中解析历史 HTML。触发器覆盖普通、批量、嵌套、原生 SQL、级联删除以及事务回滚；不依赖单个 Prisma hook。

整理每次最多 128 条，读取前按 HTML 长度估算约 8MiB UTF-16 输入预算；单篇超预算仍单独处理，不截断全文。每条带 generation 条件写回，更新／删除并发发生时，旧版本解析结果不能覆盖新版本。进程重启保留 pending 状态；无脚本或静默后台重建任务。状态计数从窄表及覆盖索引读取，避免每批重复扫描原始正文。

测试覆盖新增、嵌套、原生更新、清空、删除、级联、回滚、重启、版本竞争、中文／标点、输入边界、分组／日期／分页及片段文本转义。所有库、来源和文章均为合成数据。

本轮不执行生产迁移、部署或重启。后续升级必须先按实例版本备份和隔离演练；这份开发文档不是生产执行授权。

历史源码冻结清单保留不变；本轮只为列表读取、搜索输入、相关导出方法和搜索路由增加显式指纹对照。登录、采集、调度、备份与写入护栏仍按原指纹验证。离线导入审计严格保留旧业务行及旧搜索投影，只接受新增文章对应的初始待整理投影；未知表、列漂移和异常投影继续拒绝。

## 复现

`pnpm --filter server exec jest article-body-search.spec.ts --runInBand`

`node --test scripts/body-search-browser.test.cjs scripts/sqlite-statements.test.cjs`

`pnpm --filter server exec ts-node -r tsconfig-paths/register scripts/benchmark-body-search.ts`

基准只创建自身临时目录及合成 1809／60000 篇数据库，不接受数据库或目录路径输入；测量受保护回环 HTTP＋实际路由＋SQLite＋片段，不含浏览器渲染。查询每类 30 样本，写入每类 20 个十篇批次，报告 P50/P95、错误、投影文件增量和分批整理耗时。操作系统缓存不受控，不能当成物理冷盘或生产采集收益。

合成 HTTP、首建、投影与写入成本结果见[性能记录](LOCAL_BODY_SEARCH_PERFORMANCE.md)。
