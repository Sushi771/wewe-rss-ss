# 小红书缓存图文导出身份与安全补图

本轮订阅缓存图文的 `prepareLocalDownload` 已接到原 `ArticlePreparation.identity.exportSource`。博主目录身份使用平台/上游作者 ID 的 JSON 元组，文章身份仍使用已有平台/笔记 ID 元组，不使用标题、日期、主页字符串或本地博主备注推导身份。无可信作者 ID、非规范笔记元组或跨平台分组会拒绝保存。

图文现在复用共享来源目录与图片池：目录按可信原文发表日期、应用分组和博主备注建立，回执用稳定身份查找。改名、分组调整及不同下载日期时，完整已存内容先跳过，保留原位置与用户手写正文。身份确认和缓存快照先执行，昂贵的正文/图片字节验证延迟到首次保存或修复；跳过由保存器核验已有回执、相对路径、图片字节哈希，而非单看文件名或标记。

首次保存由原导出器生成图片名，保存器把原图片名映射到稳定笔记身份加图片 SHA256 的文件名并记录映射。缺失图片按此已核映射补齐，不覆盖已有 Markdown。此适配器不设置 `canReuseLegacyImages` 或 `seedImages`，旧不完整回执缺映射、恶意映射或字节冲突拒绝修复；不猜测原图片关联，不覆盖手写正文，不为了修复请求平台或远端图片。

共享导出元数据增加可选 `platform: 'xiaohongshu'`，对应文字为“小红书博主”；未设置时原公众号标签不变。内部视频缓存仍走原每篇独立目录，因为来源目录保存器目前明确不支持视频。本轮不扩展视频导出或小红书独立单篇入口的身份合同。

验证文件：`apps/server/src/collection/xiaohongshu-export-identity.spec.ts`。测试只用合成 SQLite 缓存形态、临时文件和真实合成 PNG 字节，覆盖平台/作者/笔记身份、原图映射与哈希、跨日期改名跳过、延迟正文核验、手写正文保护、缺图补齐、旧不可信映射拒绝及缺身份拒绝。所有网络入口由测试禁止；这些结果不能证明 redbook 真实 schema、真实作者/笔记响应、全图抓取、实际登录或平台验收。

本轮新 8 项测试已在隔离工作树使用标准 Jest/ts-jest（类型诊断开启）通过。Windows 受限沙箱曾阻断临时缓存 rename/保存器文件发布，已获准在同一离线临时目录重跑通过；不能将首次沙箱错误计为功能验收。改动辅助合同与测试 ESLint 通过。
