# 阅读列表布局小改进

## 使用体验

未勾选文章时，阅读工具栏只保留搜索、更新、下载及更多入口。勾选一篇或全选已加载文章后，已选数量、清空选择和批量导出会出现；清空后收起。文章勾选框和全选入口始终保留。

完整缓存、没有正文异常反馈的普通文章行最小高度为 56px，减少桌面列表留白。长标题在窄屏自然换行，正文缺失或重试反馈行保留原有自适应空间。搜索仍使用原图标按钮，屏幕阅读器可以识别名称、展开状态与对应搜索区域。

日期日历、日期快捷、日期错误提示、排序、搜索关键词 Chip、文章勾选、导出和正文内查找保持原有入口。工具与账号页面保持现有呈现。

## 实现与整合

- `feeds/index.tsx`：仅增加批量操作的条件呈现，以及搜索按钮的 ARIA 属性和搜索区 ID；不更改筛选、存储、路由、请求或更新逻辑。
- `feeds/list.tsx`：完整缓存且没有重试反馈或不可用状态的行增加 `article-row-ready` 类。
- `index.css`：该类使用 `min-height: 56px`；未设置固定高度，不裁剪长标题、正文反馈或操作。
- 继续复用 NextUI 的 Button、Checkbox、Tooltip 等已有组件，无新增依赖。

本改进独立基线为 `3dafadec63524257aa67498b5279559b2d3cc24f`。与筛选状态记忆的并行改动整合时，只需合并 JSX 呈现差异。合并后重跑下列检查；回滚上述三个文件中的对应差异即可恢复原呈现。
